# 眠屿前端实现说明

## 页面映射

| 规范编号 | 实现文件 | 关键状态 |
|---|---|---|
| P0 启动与年龄门 | `onboarding_screen.dart` | 成人/儿童、可选 PIN、非医疗确认、可跳过偏好 |
| P1 首页 / 眠屿 | `home_screen.dart` | 房间缩略、方案摘要、快速开始、内容入口 |
| P2 今晚沟通 | `conversation_screen.dart` | 点选、四条预制句、规则理由、重新生成 |
| P3 内容中心 | `content_center_screen.dart` | 声音/故事/呼吸/预设/收藏、年龄与审核过滤 |
| P4 故事/呼吸详情 | `content_center_screen.dart` | 时长、主题、年龄包、审核状态、模板故事标注 |
| P5 声景编辑器 | `room_editor_screen.dart` | 室内外切换、拖放、点按添加、方向按钮、音量、冻结 |
| P6 睡眠模式 | `sleep_screen.dart` | 全屏低光、剩余时间、暂停/继续、退出确认 |

| P8 睡眠档案 | `archive_screen.dart` | 播放记录与主观反馈分源展示 |
| P9 积分 | `points_screen.dart` | 仅计划开始、反馈提交两类流水 |
| P10 隐私中心 | `privacy_screen.dart` | 四项独立授权、撤回、删除本机数据 |
| P11 设置 | `settings_screen.dart` | 年龄模式、PIN、关于、非医疗说明 |

## 组件与边界

- `lib/domain/contracts.dart`：14 个冻结枚举、10 个跨模块 DTO、12 个 Port。
- `lib/data/fake_services.dart`：符合 Port 的演示数据与规则回退。
- `lib/presentation/widgets/components.dart`：按钮、来源标签、方案卡、音轨标签、空错态与非医疗页脚。
- `lib/app_controller.dart`：只编排页面状态和 Port，不访问模块 Repository。
- `room_editor_screen.dart` 的声音盒按最终交互稿重组为「室内 / 户外 / 故事」三类移动端底部面板；轻键盘与被子摩擦归入室内，柴火燃烧、夜晚森林与远雷归入户外。12 个 PNG 实体图标用于可视拖放，12 个 SVG 源图标保留在 `assets/images/icons/` 作为设计源；远雷保留禁忌验证标记。
- `sleep_screen.dart` 使用同一卧室场景图、低光覆盖、暂停 / 时长 / 退出的底部控制条，睡眠态不增加奖励化或测量化结论。
- `assets/images/scenes/reference_home.png` 作为成员四的完整初始界面参考归档；生产页面使用不含烧录文字的 `bedroom.png` 重建同一移动端结构，避免把参考图中的静态文字误当成可交互 UI。
- 浏览器交互预览使用真实用户界面，不显示 P0–P11、验收编号或“系统预览”字样。`app_pages.js` 与 `app_pages.css` 补齐首次设置、首页、今晚沟通、内容中心、详情、档案、积分、反馈、隐私和设置，并以「眠屿 / 编辑 / 档案 / 设置」作为四项一级导航；声景编辑器保持独立沉浸式界面。完整主路径为首次设置 → 点选/预制句 → 查看理由 → 房间预览与拖放 → 睡眠模式 → 次日反馈 → 个性化成长档案。
- 除声景编辑器外，普通页面使用深靛蓝抽象低光背景，不复用卧室或雨夜小院场景图；睡眠模式使用独立低光渐变，仅保留暂停、剩余时间与退出控件。

## 验收路径

1. 完成 P0 首次流程。
2. 首页进入“今晚沟通”，选择任一预制句并生成方案。
3. 查看一至两句理由、建议来源、时长和音轨摘要。
4. 进入房间，点窗切换室外；拖放或点按添加声音，并使用方向按钮微调。
5. 保存并冻结场景，开始睡前流程。
6. 睡眠模式中暂停/继续并确认退出。
7. 档案页完成三项次日反馈，查看来源标签与积分。

## 集成说明

当前为 Fake Demo。真实模块交付后，只替换 `AppPorts` 中的实现，页面和 DTO 名称保持不变。音频、数据库、LLM 与领域规则不属于本前端目录。
