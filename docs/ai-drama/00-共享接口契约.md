## 1. 与原设计的差异（已定稿）

| 原设计 | 本契约 | 原因 |
|---|---|---|
| 单卡 48GB，vLLM + Qwen3-32B | 2×RTX 3090 24GB；llama.cpp 上已运行的 `Qwen3.8-27B`（Q8，约 28GB，跨两卡） | 按现有机器 |
| Flutter 客户端 | 仍是 Flutter，代码在 `lib/`。`public/` 只是浏览器预览，这次不改 | 产品客户端是 App，不是网页 |
| 路由 `/api/v1/ai/chat`、`/api/v1/drama-jobs` | 统一挂在 `/api/v1/drama/...` | 与现有模块按前缀分组一致 |
| API 字段 camelCase | **snake_case** | 现有前端 DTO、`frontend-api` 全部是 snake_case |
| 状态机第一步 `extracting_brief` 在任务内执行 | 拆成同步接口 `POST /drama/brief`，任务只接收确认后的 `brief` | 聊天原文完全不进入任务和数据库 |
| 单一 `status` 串联所有阶段 | `status`（任务生命周期）+ `stage`（当前阶段）两个字段 | 前端判断更简单 |
| Docker 多容器 | 单容器内用 supervisord 管多进程，Nginx 统一占 8080 | 实例只暴露一个容器端口 8080 |
| 媒体用 UUID 路径直接下载 | 媒体走带签名、有过期时间的 URL | Flutter 的播放器不能带 `X-User-Id` |

## 3. 通用约定（沿用现有项目）

1. **前缀**：所有新接口都以 `/api/v1/drama/` 开头。
2. **成功响应**：`{ "data": <payload> }`。
3. **失败响应**：`{ "error": { "code": string, "message": string, "requestId": string, "details": array } }`。注意 `requestId` 是现有约定，保持 camelCase，其它字段一律 snake_case。
4. **身份**：所有接口都要求请求头 `X-User-Id`。Flutter 客户端在内存里保存匿名用户 id，并在每个请求带上。缺失时返回 `401 IDENTITY_REQUIRED`。唯一例外是媒体接口（§6.12），它用签名鉴权。
5. **年龄模式**：后端**不信任**请求头 `X-Age-Mode`，以 `user_profile.age_mode` 为准。儿童模式下除 `GET /drama/capabilities` 外的所有接口都返回 `403 DRAMA_CHILD_MODE_FORBIDDEN`。
6. **幂等**：`POST /drama/jobs` 必须带 `Idempotency-Key`（UUID v4），缺失返回 `400 IDEMPOTENCY_KEY_REQUIRED`。其它写接口可以带也可以不带，后端不依赖。
7. **时间**：ISO 8601 UTC 字符串，例如 `2026-10-08T07:30:00.000Z`。
8. **时长**：统一用秒，字段以 `_sec` 结尾，类型为数字，可带 1 位小数。
9. **请求体上限**：32KB（现有 `express.json({ limit: '32kb' })`），超出返回 `413 PAYLOAD_TOO_LARGE`。
10. **字段校验失败**：`400 INVALID_REQUEST`，`details` 为 Zod issues（现有行为）。
11. **未知字段**：请求中的未知字段由后端忽略，不报错；前端不得依赖响应里未在本文定义的字段。
12. **空值**：本文中标为 `| null` 的字段必须出现，值为 `null`，不能省略。

## 4. 枚举与固定选项

### 4.1 情绪 `DramaMood`

| 值 | 前端显示 |
|---|---|
| `calm` | 平静 |
| `warm` | 温暖 |
| `healing` | 治愈 |
| `dreamy` | 梦幻 |

### 4.2 画面风格 `VisualStyle`

| 值 | 前端显示 | 说明 |
|---|---|---|
| `watercolor` | 水彩绘本 | 默认值 |
| `paper_cut` | 剪纸夜景 | 与眠屿首页风格一致 |
| `soft_anime` | 柔和动画 | |
| `oil_pastel` | 油画棒 | |

### 4.3 时长与分镜

| 字段 | 允许值 | 默认 |
|---|---|---|
| `duration_sec` | `90`、`120`、`150` | `120` |
| `shot_count` | `6`、`7`、`8` | `6` |

故事字数由后端按 `duration_sec × 4` 计算，并夹在 300～600 字之间（90 秒约 360 字，120 秒约 480 字，150 秒约 600 字）。成片实际时长以配音为准，允许比 `duration_sec` 偏差 ±25%。

### 4.4 旁白音色

只有一个：`voice_id = "default"`，前端显示"默认旁白（温和女声）"。前端不提供选择控件。

### 4.5 任务生命周期 `DramaJobStatus`

| 值 | 含义 | 终态 |
|---|---|---|
| `queued` | 已创建，等待执行（包括重试后重新排队） | 否 |
| `running` | 正在执行某个阶段 | 否 |
| `cancelling` | 已请求取消，等待当前这次推理结束 | 否 |
| `completed` | 成片可播放 | 是 |
| `failed` | 某阶段多次重试后失败，可人工重试 | 是（可重试） |
| `cancelled` | 已取消 | 是 |

### 4.6 阶段 `DramaStage`（固定顺序，共 7 个）

| 顺序 | 值 | 前端显示 | 进度权重 | 按分镜计数 |
|---|---|---|---|---|
| 1 | `generating_story` | 创作故事 | 10 | 否 |
| 2 | `reviewing` | 安全审核 | 5 | 否 |
| 3 | `generating_storyboard` | 设计分镜 | 5 | 否 |
| 4 | `generating_character_reference` | 绘制角色设定 | 10 | 否 |
| 5 | `generating_images` | 绘制分镜画面 | 40 | 是 |
| 6 | `synthesizing_voice` | 生成旁白 | 15 | 是 |
| 7 | `composing_video` | 合成短片 | 15 | 否 |

**进度算法**（后端计算，前端只展示，不自行推算）：

```text
progress = 已完成阶段权重之和 + floor(当前阶段权重 × done / total)
```

其中 `done`、`total` 只对"按分镜计数"的阶段有意义，其它阶段在完成前计 0。`completed` 时为 100。进度只增不减（重试时保留已完成阶段的权重）。

### 4.7 阶段细节 `DramaStageDetail`

| 值 | 前端副标题 |
|---|---|
| `waiting_gpu` | 正在等待显卡空闲 |
| `loading_model` | 正在准备模型（约 1 分钟） |
| `running` | （不显示副标题） |
| `retrying` | 遇到小问题，正在自动重试 |

### 4.8 提示信息 `DramaNotice`

后端在任务进行中可以追加以下代码，前端按表显示为一行说明，不显示为错误。

| 值 | 前端文案 |
|---|---|
| `PRIVACY_REPLACED` | 已把对话中的真实姓名、地点替换为虚构名称 |
| `STORY_TEMPLATE_FALLBACK` | AI 故事未通过安全审核，已改用预先审核的模板故事 |
| `CHARACTER_PRESET_FALLBACK` | 角色设定图生成失败，已使用预置角色形象 |
| `SHOT_IMAGE_RETRIED` | 部分画面已自动重新绘制 |

## 5. 数据结构（TypeScript 描述，JSON 为 snake_case）

```ts
type DramaMood = 'calm' | 'warm' | 'healing' | 'dreamy';
type VisualStyle = 'watercolor' | 'paper_cut' | 'soft_anime' | 'oil_pastel';
type DramaJobStatus = 'queued' | 'running' | 'cancelling' | 'completed' | 'failed' | 'cancelled';
type DramaStage = 'generating_story' | 'reviewing' | 'generating_storyboard'
  | 'generating_character_reference' | 'generating_images' | 'synthesizing_voice' | 'composing_video';
type DramaStageDetail = 'waiting_gpu' | 'loading_model' | 'running' | 'retrying';
type DramaNotice = 'PRIVACY_REPLACED' | 'STORY_TEMPLATE_FALLBACK' | 'CHARACTER_PRESET_FALLBACK' | 'SHOT_IMAGE_RETRIED';

// 5.1 对话消息。只存在于 Flutter 页面内存和单次请求中，后端处理完立即丢弃。
interface DramaChatMessage {
  role: 'user' | 'assistant';
  content: string;            // user ≤ 300 字；assistant ≤ 600 字
}

// 5.2 引导状态。由后端生成，前端原样回传，后端视为"不可信提示"并重新推断。
interface DramaGuideState {
  theme: string | null;               // ≤ 30 字，例如"灯塔里看雨的猫"
  mood: DramaMood | null;
  setting: string | null;             // ≤ 40 字，例如"海边灯塔顶层"
  protagonist: string | null;         // ≤ 40 字
  visual_style: VisualStyle | null;
  forbidden_elements: string[];       // ≤ 10 项，每项 ≤ 12 字
  missing: Array<'theme' | 'mood' | 'setting'>;   // 还缺的必填项，按此顺序
}

// 5.3 故事摘要。确认页可编辑；创建任务时提交。
interface StoryBriefDto {
  theme: string;                      // 2–30 字
  mood: DramaMood;
  setting: string;                    // 2–40 字
  protagonist: string;                // 2–40 字
  visual_style: VisualStyle;
  duration_sec: 90 | 120 | 150;
  shot_count: 6 | 7 | 8;
  forbidden_elements: string[];       // 0–10 项，每项 1–12 字，自动去重、去首尾空格
  voice_id: 'default';
  privacy_replacements: string[];     // 只读说明，例如"真实姓名已替换为“小林”"；创建任务时前端原样提交，后端忽略其内容
}

// 5.4 单个阶段的状态
interface DramaStageStateDto {
  key: DramaStage;
  status: 'pending' | 'running' | 'completed' | 'failed' | 'skipped';
}

// 5.5 单个分镜的进度
interface DramaShotProgressDto {
  order: number;                      // 1 起
  image_status: 'pending' | 'generating' | 'completed' | 'failed';
  audio_status: 'pending' | 'generating' | 'completed' | 'failed';
  thumbnail_url: string | null;       // 图片完成后给出带签名的缩略图 URL（§6.12）
}

// 5.6 任务错误
interface DramaJobErrorDto {
  code: string;                       // 见 §7.2
  message: string;                    // 后端给出的中文说明，前端优先使用 §7.2 的固定文案
  retryable: boolean;
}

// 5.7 任务详情
interface DramaJobDto {
  id: string;                         // UUID v4
  status: DramaJobStatus;
  stage: DramaStage | null;           // queued 且从未开始时为 null；completed 时为 null
  stage_detail: DramaStageDetail | null;
  failed_stage: DramaStage | null;    // 仅 failed 时有值
  progress: number;                   // 0–100 整数
  stage_progress: { done: number; total: number } | null;  // 仅分镜计数阶段有值
  stages: DramaStageStateDto[];       // 永远 7 项，顺序同 §4.6
  queue_position: number | null;      // queued 时为 1 起的排队序号，否则 null
  title: string | null;               // 故事审核通过后才有
  story_source: 'llm' | 'template' | null;
  brief: StoryBriefDto;
  shots: DramaShotProgressDto[];      // 分镜生成前为空数组
  notices: DramaNotice[];
  error: DramaJobErrorDto | null;     // 仅 failed 时有值
  can_cancel: boolean;                // queued / running 时为 true
  can_retry: boolean;                 // failed 且未超过人工重试上限时为 true
  created_at: string;
  updated_at: string;
  completed_at: string | null;
}

// 5.8 列表项
interface DramaJobSummaryDto {
  id: string;
  status: DramaJobStatus;
  stage: DramaStage | null;
  progress: number;
  title: string | null;
  cover_url: string | null;           // completed 时有值
  duration_sec: number | null;        // completed 时为成片实际时长
  created_at: string;
  completed_at: string | null;
}

// 5.9 成品
interface DramaResultDto {
  job_id: string;                     // 缓存作品为 "showcase-01" 这类固定 ID
  is_showcase: boolean;
  title: string;                      // ≤ 20 字
  summary: string;                    // ≤ 80 字
  narration: string;                  // 完整旁白文本
  story_source: 'llm' | 'template';
  ai_generated: true;                 // 前端必须显示"AI 生成"标记
  duration_sec: number;
  video: { url: string; mime: 'video/mp4'; width: 720; height: 1280; size_bytes: number };
  cover_url: string;
  subtitles_url: string;              // WebVTT，前端作为 <track kind="subtitles" srclang="zh">
  shots: Array<{ order: number; image_url: string; narration_text: string; start_sec: number; duration_sec: number }>;
  media_expires_at: string;           // 以上所有 URL 的过期时间，过期后重新请求本接口
  created_at: string;
}

// 5.10 能力探测
interface DramaCapabilitiesDto {
  enabled: boolean;                   // 后端 DRAMA_ENABLED
  age_mode_allowed: boolean;          // 当前用户为成人模式时为 true
  llm: 'ready' | 'busy' | 'down';     // busy = GPU 正在跑图片/配音阶段，Qwen 暂时停用
  media_pipeline: 'ready' | 'degraded' | 'down';
  queue_length: number;               // 全局排队中 + 运行中的任务数
  active_job_id: string | null;       // 当前用户正在进行的任务
  max_user_rounds: 6;
  duration_options_sec: [90, 120, 150];
  shot_count_options: [6, 7, 8];
  visual_styles: Array<{ id: VisualStyle; label: string }>;   // 同 §4.2
  voice: { id: 'default'; label: '默认旁白（温和女声）' };
}
```

### 6.2 `POST /drama/chat`

**请求**

```json
{
  "messages": [
    { "role": "user", "content": "想听一个关于猫的故事" },
    { "role": "assistant", "content": "好呀。你希望这只猫待在什么地方呢？" },
    { "role": "user", "content": "海边的灯塔，外面在下小雨" }
  ],
  "guide_state": { "theme": "猫的故事", "mood": null, "setting": null, "protagonist": "一只猫",
                   "visual_style": null, "forbidden_elements": [], "missing": ["mood", "setting"] }
}
```

规则（后端校验，前端也要遵守）：

- `messages` 长度 1～11，必须以 `user` 开头、以 `user` 结尾，`user` / `assistant` 严格交替。
- `user` 消息条数 ≤ 6（即最多 6 轮）。第 7 轮返回 `400 DRAMA_CHAT_ROUND_LIMIT`。
- 前端的开场白（§前端文档 4.1）是本地固定文案，**不放进** `messages`。
- 第一轮 `guide_state` 传 `null`。

**响应 200**

```json
{ "data": {
  "reply": "灯塔和小雨，听起来很安静。你希望听完以后是什么感觉？比如平静、温暖，还是有点梦幻？",
  "guide_state": { "theme": "灯塔里看雨的猫", "mood": null, "setting": "海边灯塔，窗外小雨",
                   "protagonist": "一只橘猫", "visual_style": null, "forbidden_elements": [], "missing": ["mood"] },
  "suggestions": ["平静", "温暖", "梦幻"],
  "ready": false,
  "round": 2,
  "rounds_left": 4
} }
```

- `reply`：≤ 120 字，每次只问一个问题。
- `suggestions`：0～4 个快捷回复，每个 ≤ 10 字，前端渲染为可点的标签，点击等同于发送该文字。
- `ready`：`theme`、`mood`、`setting` 都不为 `null` 时为 `true`。前端据此启用"生成我的故事"按钮。
- `round`：本次请求中 `user` 消息数；`rounds_left = 6 - round`。
- `round = 6` 时，后端必须让 `reply` 收尾（不再提问），并尽量把缺失项按合理默认补齐使 `ready=true`。

**错误**：`400 DRAMA_CHAT_ROUND_LIMIT`、`400 PRODUCT_BOUNDARY_CRISIS`、`403 DRAMA_CHILD_MODE_FORBIDDEN`、`429 DRAMA_RATE_LIMITED`、`503 LLM_UNAVAILABLE`。

### 6.3 `POST /drama/brief`

**请求**：与 6.2 相同的 `{ messages, guide_state }`，不需要追加新的 user 消息。

**响应 200**

```json
{ "data": {
  "brief": {
    "theme": "灯塔里看雨的猫", "mood": "calm", "setting": "海边灯塔顶层，窗外细雨",
    "protagonist": "一只叫南瓜的橘猫", "visual_style": "watercolor",
    "duration_sec": 120, "shot_count": 6, "forbidden_elements": ["打雷"],
    "voice_id": "default", "privacy_replacements": []
  }
} }
```

- 用户没提到的字段由后端填默认值：`visual_style=watercolor`、`duration_sec=120`、`shot_count=6`。
- 对话中出现真实姓名、学校、住址、电话等时，后端替换为虚构内容，并在 `privacy_replacements` 中用一句话说明（不回显原文）。
- 必填项推断不出来时返回 `422 DRAMA_BRIEF_INCOMPLETE`，`details` 为 `[{ "field": "mood" }]` 这样的数组。

**错误**：同 6.2，外加 `422 DRAMA_BRIEF_INCOMPLETE`。

### 6.4 `POST /drama/jobs`

**请求头**：`Idempotency-Key: <uuid>`（必填）

**请求**

```json
{ "brief": { "theme": "灯塔里看雨的猫", "mood": "calm", "setting": "海边灯塔顶层，窗外细雨",
             "protagonist": "一只叫南瓜的橘猫", "visual_style": "watercolor", "duration_sec": 120,
             "shot_count": 6, "forbidden_elements": ["打雷"], "voice_id": "default", "privacy_replacements": [] } }
```

**响应**

- 新建：`202`，`{ "data": DramaJobDto }`，`status="queued"`，`stage=null`，`progress=0`。
- 同一用户、同一 `Idempotency-Key` 再次提交：`200`，返回第一次创建的任务（无论请求体是否相同）。

**校验**：`brief` 按 §5.3 约束；`theme`、`setting`、`protagonist`、`forbidden_elements` 会再做一次确定性安全检查。

**错误**：`400 IDEMPOTENCY_KEY_REQUIRED`、`400 INVALID_REQUEST`、`400 PRODUCT_BOUNDARY_CRISIS`、`422 DRAMA_BRIEF_UNSAFE`、`403 DRAMA_CHILD_MODE_FORBIDDEN`、`409 DRAMA_JOB_ALREADY_RUNNING`（`details: [{ "job_id": "..." }]`）、`503 DRAMA_QUEUE_FULL`、`503 DRAMA_DISABLED`。

并发规则：每个用户同时最多 1 个非终态任务；全局非终态任务最多 3 个（1 个运行 + 2 个排队）。

### 6.5 `GET /drama/jobs?limit=20`

`limit` 取值 1～50，默认 20。按 `created_at` 倒序，只返回当前用户的任务，不含缓存作品。

```json
{ "data": { "items": [ DramaJobSummaryDto, ... ] } }
```

### 6.6 `GET /drama/jobs/{jobId}`

### 6.7 `POST /drama/jobs/{jobId}/cancel`

- `queued` → 立即变 `cancelled`。
- `running` → 变 `cancelling`，当前这次推理结束后变 `cancelled`，不再启动新推理；已生成的中间产物保留。
- 其它状态 → `409 DRAMA_JOB_INVALID_STATE`。
- 返回最新 `DramaJobDto`。

### 6.8 `POST /drama/jobs/{jobId}/retry`

- 只允许 `failed` 且 `can_retry=true`；任务回到 `queued`，`stage` 保持为 `failed_stage`，之前完成的阶段不重做。
- 人工重试上限 3 次，超过返回 `409 DRAMA_RETRY_LIMIT`。
- 其它状态返回 `409 DRAMA_JOB_INVALID_STATE`；用户已有其它非终态任务时返回 `409 DRAMA_JOB_ALREADY_RUNNING`。
- 返回最新 `DramaJobDto`。

### 6.9 `GET /drama/jobs/{jobId}/result`

- 仅 `completed` 可用，否则 `409 DRAMA_RESULT_NOT_READY`。
- 返回 `DramaResultDto`。每次调用都签发新的媒体 URL，有效期 6 小时。

### 6.10 `DELETE /drama/jobs/{jobId}`

- 非终态任务返回 `409 DRAMA_JOB_INVALID_STATE`（先取消）。
- 删除数据库记录和 `{DRAMA_DATA_DIR}/{jobId}/` 整个目录。返回 `{ "data": { "deleted": true } }`。
- 现有 `DELETE /api/v1/users/me/data` 也必须删除该用户的全部短片任务和文件。

### 6.11 `GET /drama/showcase`

返回 `{ "data": { "items": DramaResultDto[] } }`，`is_showcase=true`。至少 1 条，答辩时即使 GPU 不可用也必须能返回。儿童模式返回 403。

### 6.12 `GET /drama/media/{jobId}/{fileName}?exp={unix秒}&sig={hex}`

- 后端返回的 URL 是以 `/api/v1/` 开头的路径，不写主机名。Flutter 用 API 基址的 origin 拼接后再播放。基址 `http://i-1.gpushare.com:54336/api/v1` 的 origin 是 `http://i-1.gpushare.com:54336`。客户端不得自己改 `exp` 或 `sig`。
- 字幕以 `shots` 里的 `start_sec`、`duration_sec`、`narration_text` 为准，由 Flutter 叠加显示。`subtitles.vtt` 仍然生成，供烧录字幕和下载。
- `fileName` 白名单正则：`^(final\.mp4|cover\.jpg|subtitles\.vtt|character\.png|shot-\d{3}\.jpg|thumb-\d{3}\.jpg)$`。
- 签名：`sig = hex(HMAC-SHA256(MEDIA_SIGNING_SECRET, "{jobId}/{fileName}:{exp}"))`。
- 支持 `Range`（视频拖动），`final.mp4` 必须已做 `+faststart`。
- 响应头：`Cache-Control: private, max-age=3600`；MIME 依次为 `video/mp4`、`image/jpeg`、`text/vtt; charset=utf-8`、`image/png`。
- 下载：Flutter 用签名后的绝对 URL 把 `final.mp4` 存到本机，文件名用故事标题。后端不需要额外的下载接口。
- 错误：签名不对或过期 `403 MEDIA_LINK_EXPIRED`；文件不存在 `404 MEDIA_NOT_FOUND`（JSON 错误包络）。客户端收到 403 时重新请求一次 result 或 showcase，用新 URL 再播。

### 6.13 `POST /drama/jobs/{jobId}/shots/{order}/regenerate`（P1）

- 仅 `completed` 任务可用；`order` 为 1～`shot_count`。
- 后端换随机种子重画该张，再重新合成视频。任务回到 `queued`，`stage=generating_images`，`stage_progress={done:0,total:1}`，完成后再次 `completed`，`result` 返回新的 URL。
- 每个任务最多重画 3 次，超过返回 `409 DRAMA_RETRY_LIMIT`。
- P1 未实现前，后端返回 `501 NOT_IMPLEMENTED`（错误包络），前端据此隐藏按钮。

## 8. 前端轮询规则

| 任务状态 | 间隔 |
|---|---|
| `queued` | 5 秒 |
| `running`、`cancelling` | 3 秒 |
| App 进入后台（`AppLifecycleState.paused`） | 15 秒 |
| 终态，或进度页被销毁 | 停止 |
| 连续 3 次网络错误 | 退避到 15 秒，并显示"网络不稳定" |

后端保证 `GET /drama/jobs/{jobId}` 只读数据库，单次耗时小于 50ms，不受 GPU 阶段影响。

## 9. 隐私与安全硬约束（两边都要做到）

1. 聊天原文只存在于 Flutter 页面的内存里，不写 `shared_preferences`、文件或日志。
2. 后端不把 `messages` 写入数据库、文件或日志；日志只允许记录条数和总字数。
3. 只有 `review_status=approved` 的故事才能进入分镜、绘图和配音。
4. 儿童模式在前端隐藏入口、在后端拒绝调用，两层都要有。
5. 成品页必须一直显示"AI 生成"标记；视频默认不自动播放、默认音量 0.6。
6. 页面上不出现"治疗""诊断""治愈失眠"等医疗表述。
