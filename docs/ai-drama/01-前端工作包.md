## 4. 运行方式

依赖只加这三个：

```yaml
dependencies:
  http: ^1.2.2
  video_player: ^2.9.2
  shared_preferences: ^2.3.2
```

`shared_preferences` 只存 `mianyu_user_id`。对话、摘要、故事正文都不存。

API 基址用编译参数，默认本机：

```dart
const kApiBase = String.fromEnvironment(
  'MIANYU_API_BASE',
  defaultValue: 'http://127.0.0.1:8787/api/v1',
);
```

```text
flutter run --dart-define=MIANYU_API_BASE=http://127.0.0.1:8787/api/v1
flutter run --dart-define=MIANYU_API_BASE=http://i-1.gpushare.com:54336/api/v1
```

Android 模拟器访问本机后端时，基址用 `http://10.0.2.2:8787/api/v1`。

仓库没有平台目录。在仓库根目录执行：

```text
flutter create . --project-name mianyu_app --org com.mianyu
```

部署机是 HTTP，不是 HTTPS。生成后要允许明文：

- `android/app/src/main/AndroidManifest.xml` 的 `<application>` 加上 `android:usesCleartextTraffic="true"`。
- `ios/Runner/Info.plist` 加上 `NSAppTransportSecurity` / `NSAllowsArbitraryLoads` = true。

只提交这些明文配置和业务代码。`flutter create` 生成的其余平台文件一并提交，否则别人无法运行。

假数据和真实接口的开关：

```text
flutter run --dart-define=MIANYU_DRAMA=fake
flutter run --dart-define=MIANYU_DRAMA=http
```

默认 `fake`。页面只依赖 `DramaPort`，不知道当前是哪一种。

## 5. 端口

`DramaPort` 的方法、路径、超时与契约 §6 对齐：

| 方法 | 请求 | 超时 |
|---|---|---|
| `capabilities()` | `GET /drama/capabilities` | 8 秒 |
| `chat(messages, guideState)` | `POST /drama/chat`，body `{ "messages", "guide_state" }` | 60 秒 |
| `extractBrief(messages, guideState)` | `POST /drama/brief` | 90 秒 |
| `createJob(brief, idempotencyKey)` | `POST /drama/jobs`，头 `Idempotency-Key` | 15 秒 |
| `listJobs({int limit = 20})` | `GET /drama/jobs?limit=20` | 10 秒 |
| `getJob(jobId)` | `GET /drama/jobs/{jobId}` | 10 秒 |
| `cancelJob(jobId)` | `POST /drama/jobs/{jobId}/cancel`，body `{}` | 10 秒 |
| `retryJob(jobId)` | `POST /drama/jobs/{jobId}/retry`，body `{}` | 10 秒 |
| `getResult(jobId)` | `GET /drama/jobs/{jobId}/result` | 10 秒 |
| `deleteJob(jobId)` | `DELETE /drama/jobs/{jobId}` | 10 秒 |
| `showcase()` | `GET /drama/showcase` | 10 秒 |
| `regenerateShot(jobId, order)` | `POST /drama/jobs/{jobId}/shots/{order}/regenerate` | 10 秒 |

HTTP 实现：

- 基址去掉末尾斜杠后拼接路径。
- 除媒体文件外，每个请求都带 `X-User-Id`。没有 id 时，先 `POST /users/anonymous`，body `{ "age_mode": "adult" 或 "child" }`，把返回的 `data.user_id` 存起来再重试原请求。
- 成功响应只取 `data`。失败响应抛 `DramaApiException(code, message, status, details)`。连不上抛 `NETWORK_ERROR`，超时抛 `REQUEST_TIMEOUT`。
- JSON 字段是 snake_case。Dart 字段用 camelCase，手写 `fromJson`，不要为了这个功能引入代码生成。
- 契约里写了 `| null` 的字段，JSON 缺键时按 `null` 处理；枚举不认识时抛 `INVALID_RESPONSE`。
- `createJob` 的幂等键在进入确认页时生成一次（`Uuid` 可用 Dart `Random` 拼一个 v4，不必加 uuid 包）。用户改了确认页任一字段后重新生成。失败重试沿用同一个键。

媒体地址：

```dart
Uri mediaUri(String apiBase, String relativeUrl) {
  final api = Uri.parse(apiBase);
  final path = Uri.parse(relativeUrl);
  return api.replace(path: path.path, query: path.query);
}
```

`apiBase` 以 `/api/v1` 结尾，`relativeUrl` 也以 `/api/v1/` 开头，所以上面要用 `replace` 覆盖 path，不能简单字符串相加，否则会变成 `/api/v1/api/v1/...`。

设置页如果改了年龄模式，并且本地已经有 `user_id`，再发一次 `PATCH /users/me`，body `{ "age_mode": "adult" 或 "child" }`。短片入口以 `capabilities.age_mode_allowed` 为准，不以本地开关单独放行。

## 6. 假数据

`FakeDrama` 实现同一个 `DramaPort`。数据放内存，进程结束就没了。延迟：对话 800 毫秒，其它接口 200 毫秒。

对话抽取规则和进度时间表，按下面做，方便和后端 fake 对得上：

- 含猫、狗、兔、熊、狐狸 → `protagonist`。
- 含灯塔、森林、海边、小屋、星空、花园 → `setting`。
- 含平静、温暖、治愈、梦幻 → 对应 `calm`、`warm`、`healing`、`dreamy`。
- 第一句非空作为 `theme`，截到 30 字。
- 按 `theme`、`mood`、`setting` 的顺序每次只问一个。第 6 轮强制补齐，`ready=true`。第 7 轮抛 `DRAMA_CHAT_ROUND_LIMIT`。
- 输入含「自杀」或「不想活」抛 `PRODUCT_BOUNDARY_CRISIS`。

任务从创建时刻起：0–2 秒 `queued`，然后按契约 §4.6 的 7 个阶段往前走，大约 36 秒后 `completed`。`progress` 用契约里的权重公式，只增不减。同一幂等键返回同一个任务。已有非终态任务时 `createJob` 抛 `DRAMA_JOB_ALREADY_RUNNING`，`details` 里带 `job_id`。

测试可以构造 `FakeDrama(failStage: DramaStage.synthesizingVoice, failTimes: 1)`。失败码用契约 §7.2 里该阶段对应的码。

播放地址在假数据模式下指向 `assets/drama_mock/sample.mp4`。B 还没给文件时，先放一张 `assets/images/content/` 里的图当封面，播放按钮提示「示例视频尚未放入」。拿到 B1 的 `sample.mp4`、`cover.jpg` 后替换。

## 7. 页面

全部使用现有暗色主题。文案短、不用感叹号、不出现「治疗」「诊断」「治愈失眠」。可点区域至少 44 逻辑像素。用户输入和接口文本一律用 `Text`，不要拼进 HTML。

### 7.1 入口

成人模式且 `capabilities.enabled == true` 时显示卡片「生成我的睡前故事短片」，副标题「聊几句，AI 为你画一段 2 分钟的晚安故事」。

放两处：

- `ConversationScreen` 顶部，进入页面时请求一次 `capabilities()`。失败就藏起卡片，不弹错误。
- 内容中心的「故事」分类顶部。

`age_mode_allowed == false` 时卡片不建，不是置灰。有 `active_job_id` 时卡片改成「故事正在生成 · {progress}%」，点击进入进度页。

### 7.2 故事短片首页 `DramaHubScreen`

- 主按钮「开始聊天」。`llm == down` 时禁用，并写「AI 暂时不可用，可以先看看示例作品」。`llm == busy` 时仍可点，下面加一行「显卡正在绘制其他故事，聊天可能需要等待」。
- 「我的作品」来自 `listJobs()`。完成项进播放页，未完成项进进度页。删除要二次确认。
- 「示例作品」来自 `showcase()`，带「示例」标记。
- 空列表写「还没有作品，先看看示例吧」。

### 7.3 对话页 `DramaChatScreen`

开场白只显示在本地，不放进 `messages`：

> 晚上好。今晚想听一个什么样的故事？可以是一个小动物、一个地方，或者一件让你安心的小事。

界面从上到下：返回、轮数「第 n/6 轮」、已收集的主题/场景/情绪/主角/禁忌、消息列表、快捷回复、输入框（最多 300 字）、按钮「生成我的故事」。

`ready == false` 时按钮禁用，并写「还差：主题 / 场景 / 情绪」。发送失败时，那条用户消息留在列表里标成可重试，但不放进下一次请求的 `messages`。第 6 轮或收到 `DRAMA_CHAT_ROUND_LIMIT` 后禁止再输入。`PRODUCT_BOUNDARY_CRISIS` 用对话框显示契约文案，确认后清空并回到首页。

返回时如果已经有消息，先问「离开后这段对话会被清除，确定离开吗？」。对话状态只放在这个页面的 `State` 里。

点「生成我的故事」调用 `extractBrief`。成功进入确认页。`DRAMA_BRIEF_INCOMPLETE` 留在本页，并用契约文案指出缺哪一项。

### 7.4 确认页 `DramaConfirmScreen`

字段和控件按契约 §5.3、§4：

| 字段 | 控件 |
|---|---|
| `theme` | 单行，2–30 字 |
| `protagonist` | 单行，2–40 字 |
| `setting` | 单行，2–40 字 |
| `mood` | 四个单选：平静、温暖、治愈、梦幻 |
| `visualStyle` | 四个单选：水彩绘本、剪纸夜景、柔和动画、油画棒 |
| `durationSec` | 约 1.5 / 2 / 2.5 分钟，对应 90 / 120 / 150 |
| `shotCount` | 6 / 7 / 8 幕 |
| `forbiddenElements` | 最多 10 个标签，每个 1–12 字 |
| 旁白 | 只读「默认旁白（温和女声）」 |
| `privacyReplacements` | 有内容才显示，不可编辑 |

本地校验不通过就不发请求。通过后调用 `createJob`。

- 成功：清空对话状态，进入进度页，并把首页留在返回栈里。不要退回到对话页。
- `DRAMA_JOB_ALREADY_RUNNING`：打开 `details` 里那个 `job_id` 的进度页。
- `DRAMA_BRIEF_UNSAFE`：按 `details[].field` 标红对应输入框。

### 7.5 进度页 `DramaProgressScreen`

显示标题（没有标题时写「正在为你创作故事」）、0–100 的进度、当前阶段中文名、契约 §4.7 的副标题、7 个阶段的状态、分镜缩略图、`notices` 的固定文案。

不要显示预计剩余时间。排队时写「排队中，前面还有 {queuePosition - 1} 个」。

`canCancel` 显示「取消生成」，确认文案：「取消后已完成的部分会保留，但不会继续生成」。`canRetry` 显示「从这一步重试」。失败且不能重试时显示「重新创建」。

轮询用契约 §8。用 `Timer`，不要并行两个请求。页面 `dispose` 时取消。用 `WidgetsBindingObserver` 监听 `AppLifecycleState.paused`，后台改为 15 秒。收到 `completed` 后如果页面还在，停轮询并进入播放页。

缩略图用 `Image.network(mediaUri(...))`。假数据模式用本地 asset。

### 7.6 播放页 `DramaPlayerScreen`

- `VideoPlayerController.networkUrl`，不要自动播放。初始化后音量设为 0.6。
- 进入页面先暂停，离开页面 `dispose` 控制器。
- 左上角始终显示「AI 生成」。示例再加「示例」。`storySource == template` 时加一行「本故事使用预先审核的模板」。
- 字幕不用解析 vtt。按播放位置在 `shots` 里找 `startSec <= position < startSec + durationSec` 的那一条，把 `narrationText` 叠在画面底部。
- 音量滑块、下载、删除（示例不可删）。下载用 `http` 把绝对 URL 存到系统临时目录，再用 `Share` 不在依赖里，所以下载按钮先把文件存到应用文档目录并提示路径。不要再加分享插件。
- 横向分镜条，点击 `seekTo` 到 `startSec`。
- 播放器报错时重新 `getResult` 一次。第二次仍失败再提示「视频暂时无法播放」。
- `regenerateShot` 收到 `NOT_IMPLEMENTED` 后隐藏「重画这一幕」。成功则回到进度页。

## 8. 错误文案

先按 `code` 查契约 §7.1 和 §7.2 的固定句子。没有再使用 `message`。再没有就显示「服务出了点问题，请稍后再试」。`LLM_UNAVAILABLE` 看 `details.first['reason']` 区分 `busy` 和 `down`。

## 9. 测试

`test/drama_port_test.dart`：

1. 假数据第 6 轮 `ready == true`，第 7 轮是 `DRAMA_CHAT_ROUND_LIMIT`。
2. 假任务能到 `completed`，进度不回退，同一幂等键是同一个 id。
3. `failStage` 之后 `retryJob` 从该阶段继续，已完成阶段不变。
4. HTTP 实现用 `http.MockClient` 断言方法、路径、`X-User-Id`、`Idempotency-Key` 和超时。
5. `mediaUri` 不会把 `/api/v1` 拼两次。
