## 一、职责概述

你是眠屿的**方案策划师**。你负责：
- 接收用户的睡前状态（情绪、时长、人声偏好、禁忌）
- 根据规则引擎生成结构化助眠方案
- 管理方案的确认、修改和历史

**你不管**：播放执行、场景编辑、收藏、内容素材本身

**重要依赖**：
- 模块1：通过 `ContentCatalogPort` 查询白名单内容
- 模块5：通过 `PreferenceQueryPort` 读取用户偏好（禁忌标签等）

## 二、必须实现的 API

### 2.1 方案生成（核心）

```
POST /v1/plans/compose
```

**请求体**（`SleepIntentDto`）：
```json
{
  "emotion": "anxious",
  "voicePreference": "unspecified",
  "availableMinutes": 15,
  "forbiddenTags": ["雷声"],
  "selectedContentIds": ["a001", "a003"]
}
```

**emotion 可选值**：`excited` | `anxious` | `wants_company` | `calm` | `unspecified`
**voicePreference 可选值**：`want` | `avoid` | `unspecified`

**响应**（`SleepPlanDto`）：
```json
{
  "id": "plan-uuid-generated",
  "type": "breath",
  "reason": "时间较短、思绪较多，先做一组呼吸，再留环境声收尾。",
  "source": "rule",
  "status": "draft",
  "durationMinutes": 15,
  "fadeOutMinutes": 2,
  "tracks": [
    {"assetId": "a001", "name": "小雨", "assetPath": "/assets/sounds/rain_light.mp3", "defaultSpace": "outdoor", "volume": 0.56, "pan": 0, "distance": 0.25}
  ],
  "breathConfig": {
    "breathId": "b001",
    "breathName": "4-7-8 呼吸法",
    "inhaleSec": 4, "holdSec": 7, "exhaleSec": 8, "cycleCount": 4
  }
}
```

**planType 可选值**：`soundscape` | `story` | `breath` | `mix`

### 2.2 方案查询

```
GET  /v1/plans/current       # 当前最新草稿方案
GET  /v1/plans/{id}         # 按ID查询
GET  /v1/plans/history       # 历史方案列表
```

### 2.3 方案确认

```
POST /v1/plans/{id}/confirm
```

**确认前校验**：
1. 至少有一条音轨
2. 音轨对应的素材 `enabled=true`，版权可用，年龄匹配
3. 若有故事：`reviewStatus=approved`，年龄匹配
4. 禁忌标签对应的素材已排除
5. 儿童模式：所有内容 `ageMode` 必须兼容

**确认失败返回**：
```json
{
  "error": "validation_error",
  "message": "故事尚未通过审核，无法确认方案",
  "code": "STORY_NOT_APPROVED"
}
```

### 2.4 方案修改

```
PATCH /v1/plans/{id}
```

**可修改字段**：
- `tracks`：增删音轨、调整音量/位置
- `breathConfig`：调整呼吸节奏（若存在）
- `fadeOutMinutes`：调整渐弱时长

**不可修改**：方案类型、故事配置（需要重新选择）

### 2.5 方案取消

```
POST /v1/plans/{id}/cancel
```

## 三、规则引擎逻辑

### 3.1 优先级顺序

```
儿童限制 > 禁忌 > 不要人声 > 短时间 > 想被陪 > 默认
```

### 3.2 规则表

| 条件 | 方案类型 | 理由模板 | tracks |
|---|---|---|---|
| `voicePreference=avoid` | `soundscape` | 你提到不想听人声，所以只保留环境声。 | 排除人声素材 |
| `availableMinutes≤15` + `emotion=excited/anxious` | `breath` | 时间较短，先做一组呼吸，再留环境声收尾。 | 呼吸+轻量环境声 |
| `emotion=wants_company` + `voicePreference≠avoid` | `story` | 你希望有人陪，选了平缓短篇。 | 故事+轻环境声 |
| `ageMode=child` | `story` 或 `soundscape` | 当前是儿童内容包，不使用成人生成对话。 | 仅儿童素材 |
| 默认 | `soundscape` | 先用稳定环境声，你可以再改。 | 基础环境声 |

### 3.3 四条预制对话映射

```python
PRESET_MAPPINGS = {
    "赶作业+雨+不要雷": {
        "type": "mix",
        "reason": "你提到不要雷声，已排除。窗外小雨，室内轻翻书或壁炉。",
        "exclude_assets": ["a008", "a012"],  # 排除雷声
        "include_assets": ["a001", "a003"],   # 包含小雨+壁炉/翻书
    },
    "考试+十五分钟": {
        "type": "breath",
        "reason": "时间短、思绪多，先呼吸再留环境声。",
        "duration_minutes": 15,
        "fade_out_minutes": 2,
        "breath_id": "b001",
    },
    "不要人声": {
        "type": "soundscape",
        "reason": "你不想听人声，只保留环境声。",
        "exclude_human_voice": True,
    },
    "心情不好+想陪": {
        "type": "story",
        "reason": "你希望有人陪，选了平缓短篇。",
        "story_filter": {"age_mode": "adult", "theme": "gentle"},
    }
}
```

### 3.4 音轨参数生成规则

```
volume:  0.56 (默认)
pan:     -1.0 ~ 1.0 (根据位置随机)
distance: 0.15 ~ 0.45 (根据位置随机)
space_type: 跟随素材 default_space
```

## 四、数据库表设计

### 4.1 sleep_plan（助眠方案聚合根）

| 字段 | 类型 | 约束 |
|---|---|---|
| plan_id | UUID | PK |
| user_id | UUID | FK → user_profile |
| plan_type | ENUM | soundscape/story/breath/mix |
| reason | VARCHAR(200) | NOT NULL, 1-200字符 |
| planned_duration_sec | INTEGER | NOT NULL, > 0 |
| fade_out_sec | INTEGER | NOT NULL, 0 ≤ value ≤ planned_duration |
| source | ENUM | rule/llm |
| status | ENUM | draft/confirmed/cancelled |
| user_modified | BOOLEAN | NOT NULL, 默认 false |
| created_at | TIMESTAMP | NOT NULL |
| confirmed_at | TIMESTAMP | 可空，status=confirmed 时非空 |

### 4.2 sleep_plan_track（方案音轨）

| 字段 | 类型 | 约束 |
|---|---|---|
| plan_track_id | UUID | PK |
| plan_id | UUID | FK → sleep_plan |
| asset_id | UUID | FK → 模块1 audio_asset |
| volume | DECIMAL(4,3) | 0.000-1.000 |
| pan | DECIMAL(4,3) | -1.000-1.000 |
| distance | DECIMAL(4,3) | 0.000-1.000 |
| space_type | ENUM | indoor/outdoor |
| sequence_no | INTEGER | > 0 |

**唯一约束**：(plan_id, sequence_no)

### 4.3 story_config（故事配置）

| 字段 | 类型 | 约束 |
|---|---|---|
| story_config_id | UUID | PK |
| plan_id | UUID | FK → sleep_plan，UNIQUE |
| story_id | UUID | FK → 模块1 story_template |
| theme | VARCHAR(50) | NOT NULL |
| tone | VARCHAR(32) | NOT NULL |
| speech_rate | DECIMAL(4,2) | 0.50-1.50 |
| duration_sec | INTEGER | NOT NULL, > 0 |
| ending_mode | ENUM | environment_only_then_fade |

### 4.4 breath_config（呼吸训练配置）

| 字段 | 类型 | 约束 |
|---|---|---|
| breath_config_id | UUID | PK |
| plan_id | UUID | FK → sleep_plan，UNIQUE |
| breath_id | UUID | FK → 模块1 breath_template |
| breath_type | VARCHAR(32) | NOT NULL |
| inhale_sec | INTEGER | NOT NULL, > 0 |
| hold_sec | INTEGER | NOT NULL, >= 0 |
| exhale_sec | INTEGER | NOT NULL, > 0 |
| cycle_count | INTEGER | NOT NULL, > 0 |
| duration_sec | INTEGER | NOT NULL, > 0 |

## 六、方案确认校验清单

在确认方案前，必须全部通过：

- [ ] `sleep_plan_track` 至少有一条
- [ ] 每条音轨对应的 `audio_asset.enabled = true`
- [ ] 每条音轨对应的 `audio_asset.copyright_status` 属于 `cleared` 类
- [ ] 每条音轨的 `age_mode` 与用户 `age_mode` 兼容
- [ ] 音轨不命中 `SleepIntent.forbidden_tags`
- [ ] 若有故事：`story_template.review_status = approved`
- [ ] 若有故事：`story_template.age_mode` 与用户兼容
- [ ] 儿童模式：所有内容 `age_mode = child`
- [ ] `planned_duration_sec > 0`
- [ ] `fade_out_sec ≤ planned_duration_sec`
