## 一、职责概述

你是眠屿的**睡眠执行引擎**。你负责：
- 睡眠会话的启动、暂停、恢复、停止
- 多轨音频的编排和执行
- 播放阶段和事件的记录
- 向模块5发布 `PlanStartedFact` 事件

**你不管**：方案生成逻辑、场景编辑、反馈积分

**关键约束**：
- `active_playback_sec` **不是睡眠时长**，只是播放时长
- 不能写 `asleep_at`、`sleep_duration` 等无证据字段
- 故事结束后必须关闭人声、只留环境声

## 二、必须实现的 API

### 2.1 开始会话

```
POST /v1/sessions/start
```

**请求体**：
```json
{
  "planId": "plan-uuid",
  "sceneConfigId": "sc-uuid"
}
```

**前置校验**：
- [ ] 方案 `status=confirmed`，属于当前用户
- [ ] 场景 `lifecycle_status=handed_off`，属于当前用户
- [ ] 场景至少有一个 `enabled=true` 的声源

**创建会话**：
```json
{
  "id": "session-uuid",
  "planId": "plan-uuid",
  "sceneConfigId": "sc-uuid",
  "status": "preparing",
  "plannedDurationSec": 1800,
  "fadeOutSec": 300,
  "startedAt": null,
  "activePlaybackSec": 0,
  "pausedSec": 0,
  "createdAt": "2026-09-23T22:00:00Z"
}
```

**编排播放阶段**：
根据 `SleepPlan.type` 决定阶段顺序：
```
breath → story → soundscape → fade_out
```

**发布事件**：
- `session_preparing`：会话创建
- 资源加载完成后：`session_started`
- 发布 `PlanStartedFact`（供模块5消费）

**错误响应**：
```json
{"error": "validation_error", "message": "方案尚未确认", "code": "PLAN_NOT_CONFIRMED"}
```

### 2.2 暂停

```
POST /v1/sessions/{id}/pause
```

**行为**：
- `status: running → paused`
- 暂停计时器（暂停时间累加到 `paused_sec`）
- 记录事件：`paused`

### 2.3 恢复

```
POST /v1/sessions/{id}/resume
```

**行为**：
- `status: paused → running`
- 恢复计时
- 记录事件：`resumed`

### 2.4 停止

```
POST /v1/sessions/{id}/stop
```

**请求体**：
```json
{
  "reason": "user_ended"   // user_ended | app_interrupted | audio_engine_error
}
```

**stopReason 可选值**：
- `timer_completed`：定时完成（正常结束）
- `user_ended`：用户主动退出
- `user_cancelled_before_start`：未开始就退出
- `app_interrupted`：应用被系统中断
- `audio_engine_error`：音频引擎错误
- `resource_load_failed`：资源加载失败
- `validation_failed`：校验失败

**行为**：
- 计算 `active_playback_sec`（排除 `paused_sec`）
- 写入 `ended_at`
- `status` 改为终态（`completed`/`cancelled`/`failed`）
- 记录事件：`session_ended`

### 2.5 会话详情

```
GET /v1/sessions/{id}
```

### 2.6 历史会话

```
GET /v1/sessions/history
```

**响应**：
```json
{
  "sessions": [
    {
      "id": "session-uuid",
      "planId": "plan-uuid",
      "status": "completed",
      "plannedDurationSec": 1800,
      "activePlaybackSec": 1720,
      "startedAt": "2026-09-22T22:00:00Z",
      "endedAt": "2026-09-22T22:28:40Z",
      "stopReason": "timer_completed"
    }
  ],
  "total": 1
}
```

## 三、播放阶段编排

### 3.1 阶段类型

| 类型 | 说明 | 数据来源 |
|---|---|---|
| `breath` | 呼吸训练 | `breath_config` |
| `story` | 故事朗读 | `story_config` |
| `soundscape` | 纯声景 | `scene_config.sources` |
| `fade_out` | 渐弱关闭 | `sleep_plan.fade_out_sec` |

### 3.2 阶段顺序

```
有 breath → breath → story → soundscape → fade_out
有 story 无 breath → story → soundscape → fade_out
仅有 soundscape → soundscape → fade_out
```

### 3.3 故事结束处理

当故事阶段完成时：
1. 记录事件：`story_finished`
2. 人声音轨静音
3. 切换到纯环境声阶段
4. 记录事件：`voice_removed`

### 3.4 渐弱处理

`fade_out` 阶段：
- 记录事件：`fade_started`
- 音量从当前值单调下降到 0
- 记录事件：`fade_completed`
- 状态改为 `completed`

## 四、数据库表设计

### 4.1 sleep_session（睡眠会话）

| 字段 | 类型 | 约束 |
|---|---|---|

| current_stage | ENUM | 可空 |

| fade_out_sec | INTEGER | 0-1800，且 ≤ planned_duration |
| started_at | TIMESTAMP | 可空 |
| ended_at | TIMESTAMP | 可空 |
| active_playback_sec | INTEGER | >= 0 |
| paused_sec | INTEGER | >= 0 |
| stop_reason | ENUM | 可空，终态时必填 |

| master_volume_end | DECIMAL(4,3) | 可空 |

| device_data_authorized | BOOLEAN | 默认 false |

| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### 4.2 playback_stage（播放阶段）

| 字段 | 类型 | 约束 |
|---|---|---|
| stage_id | UUID | PK |
| session_id | UUID | FK → sleep_session |
| stage_type | ENUM | breath/story/soundscape/fade_out |
| sequence_no | SMALLINT | >= 1，UNIQUE(session_id, sequence_no) |
| status | ENUM | pending/running/paused/completed/skipped/failed |
| planned_duration_sec | INTEGER | 可空 |
| actual_duration_sec | INTEGER | >= 0 |
| started_at | TIMESTAMP | 可空 |
| ended_at | TIMESTAMP | 可空 |
| skip_reason | VARCHAR(100) | 可空 |
| record_source | ENUM | 固定 playback_record |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### 4.3 playback_event（播放事件，只追加）

| 字段 | 类型 | 约束 |
|---|---|---|
| event_id | UUID | PK |
| session_id | UUID | FK → sleep_session |
| stage_id | UUID | FK → playback_stage，可空 |
| scene_audio_source_id | UUID | 可空，逻辑引用 |
| event_type | ENUM | 见下表 |
| occurred_at | TIMESTAMP | NOT NULL |
| old_value | VARCHAR(200) | 可空 |
| new_value | VARCHAR(200) | 可空 |
| error_code | VARCHAR(50) | 可空 |
| detail_json | JSON | 可空 |

**eventType 可选值**：
- `session_preparing` / `session_started` / `session_ended`
- `stage_started` / `stage_completed` / `stage_skipped`
- `track_started` / `track_stopped`
- `paused` / `resumed`
- `volume_changed`
- `story_finished` / `voice_removed`
- `fade_started` / `fade_completed`
- `resource_missing` / `playback_error`

## 五、PlanStartedFact 事件

### 5.1 事件定义

```json
{
  "eventType": "plan_started",
  "sessionId": "session-uuid",
  "planId": "plan-uuid",
  "userId": "user-uuid",
  "occurredAt": "2026-09-23T22:00:00Z"
}
```

### 5.2 集成方式（MVP）

MVP 使用**进程内事件总线**（不引入消息队列）：

```python
class PlanStartedFactPublisher:
    def __init__(self, handlers: List[Callable]):
        self.handlers = handlers

    def publish(self, fact: PlanStartedFact):
        for handler in self.handlers:
            handler(fact)

# 集成时注册模块5的处理器
publisher = PlanStartedFactPublisher([growth_module.handle_plan_started])
```

## 六、禁止事项

- ❌ 不调用 AI
- ❌ 不修改方案或场景
- ❌ 不计算睡眠质量
- ❌ 不把播放时长称为睡眠时长
- ❌ 不更新偏好和积分
- ❌ 无授权不采集噪声，不保存原始录音

## 七、验收清单

- [ ] 非确认方案拒绝启动（返回 `validation_error`）
- [ ] 暂停时 `paused_sec` 同步累加
- [ ] 故事结束后只留环境声
- [ ] 渐弱音量单调下降到 0
- [ ] 所有终态都有正确的 `stop_reason`
- [ ] `active_playback_sec` 不含暂停时间
- [ ] 事件记录完整（每个状态变化都有事件）
- [ ] `PlanStartedFact` 被发布
