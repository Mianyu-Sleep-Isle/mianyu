## 一、职责概述

你是眠屿的**成长记录员**。你负责：
- 次日主观反馈的收集和存储
- 用户偏好画像的管理
- 健康积分的记录
- 推荐和报告的数据基础

**你不管**：方案生成、场景编辑、播放执行

**关键约束**：
- 反馈是**用户主动填写的**，不能被设备数据覆盖
- 积分只追加、不扣分，不依赖播放时长或睡眠时长
- 报告数据必须带来源标签，不合并为综合评分

## 二、必须实现的 API

### 2.1 提交反馈

```
POST /v1/feedback
```

**请求体**（`MorningFeedbackDto`）：
```json
{
  "sessionId": "session-uuid",
  "fallAsleepEase": "easy",
  "soundComfort": "comfortable",
  "voiceNextTime": "want",
  "note": "今晚雨声很舒服"
}
```

**fallAsleepEase 可选值**：`easy` | `normal` | `difficult` | `unknown`
**soundComfort 可选值**：`comfortable` | `acceptable` | `uncomfortable`
**voiceNextTime 可选值**：`want` | `avoid` | `unspecified`

**幂等校验**：
- 同一 `sessionId` 只能提交一次
- 重复提交返回已有记录，不报错

**副作用**：
1. 写入 `morning_feedback`
2. 更新 `preference_profile`（只更新本次明确表达的偏好）
3. 追加 `points_ledger`（`feedback_submitted` 事件）

### 2.2 查询反馈

```
GET /v1/feedback/{sessionId}
```

**响应**：
```json
{
  "feedbackId": "fb-uuid",

  "fallAsleepEase": "easy",
  "soundComfort": "comfortable",
  "voiceNextTime": "want",
  "note": "今晚雨声很舒服",
  "recordSource": "subjective_feedback",
  "submittedAt": "2026-09-23T08:00:00Z"
}
```

### 2.3 查询偏好

## 三、积分规则

### 3.1 积分来源

| 事件 | 积分 | 触发时机 | 幂等键 |
|---|---|---|---|
| `plan_started` | +5 | 模块4发布 `PlanStartedFact` | `points:{userId}:plan_started:{planId}` |
| `feedback_submitted` | +10 | 用户提交次日反馈 | `points:{userId}:feedback_submitted:{feedbackId}` |

### 3.2 明确禁用

积分**不得**读取或派生自：
- ❌ 播放分钟数
- ❌ 在线时长
- ❌ 是否完整播放
- ❌ 睡眠总时长
- ❌ 深睡时长
- ❌ 夜间清醒次数
- ❌ 连续签到天数
- ❌ 中途退出、某天未使用

### 3.3 积分流水约束

- `points_delta > 0`（只加分）
- `balance_after = 上一条 balance + 本次 delta`
- 同一 `idempotency_key` 只插入一次

## 五、PlanStartedFact 处理器

### 5.1 事件格式（来自模块4）

```json
{
  "eventType": "plan_started",
  "sessionId": "session-uuid",
  "planId": "plan-uuid",
  "userId": "user-uuid",
  "occurredAt": "2026-09-23T22:00:00Z"
}
```

### 5.2 处理逻辑

```python
def handle_plan_started(fact: PlanStartedFact):
    # 1. 检查幂等键是否已存在
    existing = points_ledger.find_by_idempotency_key(f"points:{fact.userId}:plan_started:{fact.planId}")
    if existing:
        return  # 幂等，跳过

    # 2. 计算余额
    last_entry = points_ledger.latest_for_user(fact.userId)
    new_balance = (last_entry.balance_after if last_entry else 0) + 5

    # 3. 写入流水
    points_ledger.insert(
        user_id=fact.userId,
        event_type="plan_started",
        related_id=fact.planId,
        idempotency_key=f"points:{fact.userId}:plan_started:{fact.planId}",
        points_delta=5,
        balance_after=new_balance,
        remark="按计划开始睡前流程",
        occurred_at=fact.occurredAt
    )
```

## 六、偏好更新规则

### 6.1 反馈触发的更新

| 反馈字段 | 偏好更新 | 说明 |
|---|---|---|
| `voiceNextTime=want` | `voice_preference = want` | 明确要人声 |
| `voiceNextTime=avoid` | `voice_preference = avoid` | 明确不要人声 |
| `soundComfort=uncomfortable` | 追加禁忌标签（若能映射） | 声音不舒适 |
| 用户文字输入 | 禁止直接写入偏好 | 必须先映射到受控标签并确认 |

### 6.2 用户主动设置

用户直接修改偏好设置时，直接更新对应字段。

- ❌ 不因播放时长、深睡、连续签到发积分
