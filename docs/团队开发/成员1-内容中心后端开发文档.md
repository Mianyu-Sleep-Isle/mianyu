## 一、职责概述

你是眠屿的**内容仓库管理员**。你负责：
- 所有声音素材、故事模板、呼吸训练模板的目录和元数据
- 内容白名单、年龄过滤、审核状态、版权状态
- 场景收藏管理
- 向其他模块提供只读的内容编号

**你不管**：方案生成、场景配置、播放、会话、反馈

## 二、必须实现的 API

### 2.1 声音素材

```
GET /v1/content/audio
GET /v1/content/audio/{assetId}
```

**响应示例**：
```json
{
  "id": "a001-uuid",
  "name": "小雨",
  "category": "rain",
  "assetPath": "/assets/sounds/rain_light.mp3",
  "ageMode": "adult",
  "reviewStatus": "approved",
  "copyrightStatus": "owned",
  "enabled": true,
  "durationMinutes": 60,
  "createdAt": "2026-09-01T00:00:00Z",
  "updatedAt": "2026-09-01T00:00:00Z"
}
```

**过滤参数**：
- `?category=rain` 按分类筛选
- `?ageMode=child` 按年龄模式筛选
- `?enabled=true` 只返回启用的
- 三者可组合

### 2.2 故事模板

```
GET /v1/content/stories
GET /v1/content/stories/{storyId}
```

**响应示例**：
```json
{
  "id": "s001-uuid",
  "name": "森林小径",
  "theme": "nature",
  "durationMinutes": 5,
  "ageMode": "adult",
  "reviewStatus": "approved",
  "contentRef": "/assets/stories/forest_path.txt",
  "createdAt": "2026-09-01T00:00:00Z",
  "updatedAt": "2026-09-01T00:00:00Z"
}
```

**关键约束**：只有 `reviewStatus=approved` 的故事才能被前端展示

### 2.3 呼吸训练模板

```
GET /v1/content/breath
GET /v1/content/breath/{breathId}
```

**响应示例**：
```json
{
  "id": "b001-uuid",
  "name": "4-7-8 呼吸法",
  "breathType": "relaxing",
  "durationMinutes": 5,
  "inhaleSec": 4,
  "holdSec": 7,
  "exhaleSec": 8,
  "cycleCount": 4,
  "instruction": "吸气4秒，屏息7秒，呼气8秒",
  "createdAt": "2026-09-01T00:00:00Z",
  "updatedAt": "2026-09-01T00:00:00Z"
}
```

### 2.4 预设场景

```
GET /v1/content/presets
```

**响应示例**：
```json
{
  "id": "p001-uuid",
  "name": "雨夜小屋",
  "description": "窗外雨声，室内壁炉",
  "suitableContext": "relaxation",
  "sceneConfigId": "sc001-uuid",
  "enabled": true,
  "createdAt": "2026-09-01T00:00:00Z"
}
```

> 注意：`sceneConfigId` 引用模块3的场景配置，不复制场景内容

### 2.5 收藏管理

```
POST   /v1/content/favorites          # 收藏场景
DELETE /v1/content/favorites/{id}    # 取消收藏
GET    /v1/content/favorites         # 我的收藏列表
```

**收藏请求体**：
```json
{
  "sceneConfigId": "sc001-uuid"
}
```

**收藏响应**：
```json
{
  "favoriteId": "f001-uuid",
  "sceneConfigId": "sc001-uuid",
  "favoritedAt": "2026-09-23T10:00:00Z"
}
```

**幂等规则**：同一用户对同一场景只能有一条收藏，重复收藏返回已有记录

## 三、数据库表设计

### 3.1 audio_asset（声音素材）

| 字段 | 类型 | 约束 |
|---|---|---|
| asset_id | UUID | PK |
| asset_name | VARCHAR(100) | NOT NULL |
| category | VARCHAR(32) | NOT NULL |
| asset_uri | VARCHAR(500) | NOT NULL |
| duration_sec | INTEGER | NOT NULL, > 0 |
| default_space | ENUM | indoor/outdoor/either |
| age_mode | ENUM | adult/child |
| copyright_status | ENUM | owned/licensed/public_domain/pending_review/restricted/expired |
| enabled | BOOLEAN | NOT NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

**检查约束**：`enabled=true` 时 `copyright_status` 必须为 `cleared` 类

### 3.2 story_template（故事模板）

| 字段 | 类型 | 约束 |
|---|---|---|
| story_id | UUID | PK |
| story_name | VARCHAR(100) | NOT NULL |
| theme | VARCHAR(50) | NOT NULL |
| duration_sec | INTEGER | NOT NULL, > 0 |
| content_ref | VARCHAR(500) | NOT NULL |
| age_mode | ENUM | adult/child |
| review_status | ENUM | draft/pending/approved/rejected/disabled |
| voice_id | UUID | 可空 |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

**检查约束**：只有 `review_status=approved` 的故事能被前端使用

### 3.3 breath_template（呼吸训练模板）

| 字段 | 类型 | 约束 |
|---|---|---|
| breath_id | UUID | PK |
| breath_name | VARCHAR(100) | NOT NULL |
| breath_type | VARCHAR(32) | NOT NULL |
| duration_sec | INTEGER | NOT NULL, > 0 |
| instruction | TEXT | NOT NULL |
| inhale_sec | INTEGER | NOT NULL, > 0 |
| hold_sec | INTEGER | NOT NULL, >= 0 |
| exhale_sec | INTEGER | NOT NULL, > 0 |
| cycle_count | INTEGER | NOT NULL, > 0 |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### 3.4 preset_scene（预设场景条目）

| 字段 | 类型 | 约束 |
|---|---|---|
| preset_scene_id | UUID | PK |
| scene_name | VARCHAR(100) | NOT NULL |
| scene_description | VARCHAR(500) | NOT NULL |
| suitable_context | VARCHAR(50) | NOT NULL |
| scene_config_id | UUID | FK → 模块3 scene_config |
| enabled | BOOLEAN | NOT NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### 3.5 scene_favorite（场景收藏）

| 字段 | 类型 | 约束 |
|---|---|---|
| favorite_id | UUID | PK |
| user_id | UUID | FK → user_profile |
| scene_config_id | UUID | FK → 模块3 scene_config |
| favorited_at | TIMESTAMP | NOT NULL |
| | | UNIQUE(user_id, scene_config_id) |

## 六、独立运行要求

### 6.1 必须能独立运行

你的后端服务启动后，即使其他模块还没开发，也必须能：
- 启动 HTTP 服务器（`python main.py` 或 `node index.js`）
- 访问 `/v1/content/audio` 返回素材列表
- 访问 `/v1/content/stories` 返回故事列表
- 收藏 API 正常工作

### 6.2 测试方法

```bash
# 启动后端
python main.py

# 测试声音列表
curl http://localhost:8080/v1/content/audio

# 测试儿童素材过滤
curl http://localhost:8080/v1/content/audio?ageMode=child

# 测试收藏
curl -X POST http://localhost:8080/v1/content/favorites \
  -H "Content-Type: application/json" \
  -d '{"sceneConfigId": "test-scene-001"}'
```

## 七、禁止事项

- ❌ 不生成助眠方案
- ❌ 不保存场景配置
- ❌ 不直接启动播放器
- ❌ 不更新用户偏好
- ❌ 不修改应用入口或公共契约
- ❌ 不接受自由文本作为状态值（分类、主题等必须是受控值）

## 八、验收清单

完成开发后，自检以下全部通过：

- [ ] `GET /v1/content/audio` 返回12种以上声音素材
- [ ] `GET /v1/content/audio?ageMode=child` 只返回儿童素材
- [ ] `GET /v1/content/audio/{a012}` 返回 `enabled=false`
- [ ] `GET /v1/content/stories` 只返回 `reviewStatus=approved` 的故事
- [ ] `GET /v1/content/breath` 返回呼吸训练列表
- [ ] 收藏 API 幂等（重复收藏返回已有记录）
- [ ] 取消收藏成功
- [ ] 数据库使用 UUID 主键，时间用 UTC
- [ ] API 错误时返回统一格式：`{"error": "...", "message": "..."}`
- [ ] 单元测试覆盖核心逻辑（内容过滤、白名单检查）
