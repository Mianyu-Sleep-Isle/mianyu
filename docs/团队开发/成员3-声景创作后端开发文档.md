## 一、职责概述

你是眠屿的**空间设计师**。你负责：
- 场景配置的管理（保存、冻结、版本化）
- 场景内声源的位置、音量、空间属性
- 室内外场景的元数据

**你不管**：方案生成逻辑、播放执行、反馈积分

**关键概念**：
- `Scene`：编辑中的运行时聚合（内存对象，不存数据库）
- `SceneConfig`：已保存的聚合（存入数据库）
- 版本号：每次调整已冻结场景产生新版本

## 二、必须实现的 API

### 2.1 场景查询

```
GET /v1/scenes/current
```

**响应**（`SceneConfigDto`）：
```json
{
  "id": "sc001-uuid",
  "name": "我的睡前小屋",
  "status": "handed_off",
  "version": 2,
  "spaceType": "indoor",
  "environmentType": "bedroom",
  "bedPosition": {"x": 0.5, "y": 0.75},
  "sources": [
    {
      "id": "src001",
      "track": {"assetId": "a001", "name": "小雨", "defaultSpace": "outdoor"},
      "space": "outdoor",
      "x": 0.24,
      "y": 0.28,
      "volume": 0.56,
      "enabled": true
    }
  ],
  "createdAt": "2026-09-20T10:00:00Z",
  "updatedAt": "2026-09-23T08:00:00Z"
}
```

### 2.2 保存草稿

```
POST /v1/scenes/save-draft
```

**请求体**：
```json
{
  "id": "sc001-uuid",          // 可空，空=新建
  "name": "我的睡前小屋",
  "sources": [
    {
      "assetId": "a001",
      "space": "outdoor",
      "x": 0.24,
      "y": 0.28,
      "volume": 0.56,
      "enabled": true
    },
    {
      "assetId": "a003",
      "space": "indoor",
      "x": 0.50,
      "y": 0.60,
      "volume": 0.40,
      "enabled": true
    }
  ]
}
```

**行为规则**：
- 若 `id` 为空：创建新场景（`version=1`）
- 若 `id` 对应 `status=draft`：更新同一版本
- 若 `id` 对应 `status=handed_off`：拒绝（需先冻结）
- 若 `id` 对应 `status=retired`：拒绝

**响应**：返回完整的 `SceneConfigDto`

### 2.3 冻结场景

```
POST /v1/scenes/freeze
```

**请求体**：
```json
{
  "id": "sc001-uuid"
}
```

**校验**：
- [ ] 场景存在且 `status=draft`
- [ ] 至少有一个 `enabled=true` 的声源
- [ ] 每个声源的 `assetId` 对应模块1的可用素材

**行为**：
- `status` 改为 `handed_off`
- 写入 `handed_off_at`
- 整份聚合（主表+声源）变为只读

**响应**：
```json
{
  "id": "sc001-uuid",
  "status": "handed_off",
  "handedOffAt": "2026-09-23T08:00:00Z",
  ...
}
```

### 2.4 调整已冻结场景

```
POST /v1/scenes/adjust
```

**场景**：`id` 对应 `status=handed_off`

**行为**：
- 生成新版本：`version = 旧version + 1`
- 新增 `scene_config_id`
- 复制全部声源（分配新 `source_id`）
- 状态回到 `draft`

**响应**：新版本的完整 `SceneConfigDto`

## 三、坐标系统

### 3.1 归一化坐标系

```
范围：0.00000 – 1.00000
原点：当前空间画布左上角
X轴：向右递增
Y轴：向下递增
```

### 3.2 有效区域

```
有效 X：0.04 – 0.88（左右留边）
有效 Y：0.08 – 0.82（上下留边）
床位参考：x=0.50, y=0.75
```

### 3.3 空间类型

| 值 | 说明 |
|---|---|
| `indoor` | 室内（卧室） |
| `outdoor` | 室外（雨夜小院） |

切换室内外**不重置**已选声源。人在室外时室内音变远、室外音变近（由前端控制音量衰减，后端只存原始参数）。

## 四、数据库表设计

### 4.1 scene_config（场景配置聚合根）

| 字段 | 类型 | 约束 |
|---|---|---|
| scene_config_id | UUID | PK |
| scene_family_id | UUID | UNIQUE 组成列 |
| previous_version_id | UUID | FK → scene_config，UNIQUE，可空 |
| user_id | UUID | FK → user_profile |
| scene_name | VARCHAR(100) | NOT NULL |
| space_type | ENUM | indoor/outdoor |
| environment_type | ENUM | bedroom/rain_courtyard/other |
| reverb_type | ENUM | none/indoor_soft/outdoor_open |
| bed_x | DECIMAL(6,5) | 0.00000-1.00000 |
| bed_y | DECIMAL(6,5) | 0.00000-1.00000 |
| source_plan_id | UUID | FK → 模块2 sleep_plan，可空 |
| creation_method | ENUM | preset/plan_generated/user_created/copied/imported |
| config_version | INTEGER | >= 1，UNIQUE(scene_family_id, config_version) |
| lifecycle_status | ENUM | draft/handed_off/retired |
| handed_off_at | TIMESTAMP | 可空，handed_off 时非空 |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

### 4.2 scene_audio_source（场景声源）

| 字段 | 类型 | 约束 |
|---|---|---|
| source_id | UUID | PK |
| scene_config_id | UUID | FK → scene_config |
| asset_id | UUID | FK → 模块1 audio_asset |
| space_type | ENUM | indoor/outdoor |
| position_x | DECIMAL(6,5) | 0.00000-1.00000 |
| position_y | DECIMAL(6,5) | 0.00000-1.00000 |
| base_volume | DECIMAL(4,3) | 0.000-1.000 |
| pan | DECIMAL(4,3) | -1.000-1.000 |
| distance | DECIMAL(4,3) | 0.000-1.000 |
| loop_mode | ENUM | once/loop/interval |
| interval_sec | INTEGER | 可空，loop_mode=interval 时必填且 > 0 |
| fade_in_sec | INTEGER | >= 0 |
| fade_out_sec | INTEGER | >= 0 |
| enabled | BOOLEAN | NOT NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

**唯一约束**：UNIQUE(source_id, scene_config_id)（供元素绑定外键）

### 4.3 scene_element（场景元素，可选）

MVP 可暂时不做。可选实现：
- `element_id` / `scene_config_id` / `element_name` / `element_type`
- `position_x` / `position_y` / `space_type` / `z_order`
- `bound_source_id`（可选绑定到声源）

## 五、版本化规则

### 5.1 新建场景

```
scene_family_id = 新 UUID
scene_config_id = 新 UUID
config_version = 1
lifecycle_status = draft
previous_version_id = NULL
```

### 5.2 调整已冻结场景

```
scene_family_id = 旧值（不变）
scene_config_id = 新 UUID
config_version = 旧 version + 1
lifecycle_status = draft
previous_version_id = 旧 scene_config_id
```

复制全部声源，每个分配新 `source_id`

### 5.3 冻结

```
lifecycle_status = handed_off
handed_off_at = 当前 UTC 时间
```

冻结后整份聚合只读，不能修改。

## 六、模块交接

### 6.1 输入（来自模块2）

通过 `source_plan_id` 引用已确认方案。
方案生成时模块2提供：
- 推荐的素材列表
- 室内外偏好

### 6.2 输出（给模块4）

模块4按 `scene_config_id` 查询已冻结场景，读取：
- 所有 `enabled=true` 的声源
- 每个声源的 `asset_id`、`position`、`volume`、`pan`、`distance`、`loop_mode`

**模块4不能修改场景**。
