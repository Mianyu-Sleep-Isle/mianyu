# 眠屿前端实际交互说明

版本：当前浏览器预览 `system_preview.html?v=59`  
文档性质：以当前代码和可运行页面为准的交互记录，不是需求稿  
对应实现：`system_preview.html`、`app_pages.js`、`app_pages.css`

## 1. 阅读范围

眠屿当前浏览器预览由两部分组成：

1. `app_pages.js` 生成首次设置、首页、沟通、内容中心、详情、档案、反馈、积分、设置和隐私页面。
2. `system_preview.html` 提供声景编辑器、睡眠模式、编辑器面板和声音拖放交互。

页面状态主要保存在浏览器内存中。刷新页面后会回到首次设置，当前不代表已经接入真实音频、数据库或账号服务。

## 2. 实际入口与导航关系

### 2.1 首次进入

打开 `index.html` 或 `system_preview.html` 后，实际首先显示“欢迎来到眠屿”首次设置页，而不是首页。

流程为：

```text
选择成人/儿童模式
  → 设置本机 PIN（可跳过）
  → 勾选非医疗说明
  → 选择偏好（可跳过）
  → 进入眠屿首页
```

未选择成人或儿童模式时，“继续”按钮不可用；非医疗说明未勾选时，“确认并继续”不可用。

### 2.2 实际主入口

首页不是传统的底部 Tab 页面，而是岛屿物件导航：

| 可点击物件/区域 | 实际结果 |
|---|---|
| 房门 / “编辑” | 进入声景编辑器 |
| 邮箱 / “档案” | 进入睡眠档案 |
| 长椅上的钟表 / “设置” | 进入设置 |
| 首页 AI 沟通卡片 | 进入“开始沟通” |
| “探索助眠内容” | 进入内容中心 |

普通信息页内部使用左上角返回键。返回栈没有上一页时会回到首页。编辑器和睡眠模式不显示普通页面的底部导航。

## 3. 首页实际交互

首页标题区域显示眠屿品牌和夜晚岛屿场景，岛屿中包含房门、档案邮箱和设置钟表。首页底部为 AI 沟通卡片，当前文案是：

- “晚上好，我在这里”
- “今晚想聊些什么？”
- “告诉我此刻的感受，一起找到适合今晚的陪伴。”
- 橙色按钮：“开始沟通”
- 下方只保留“探索助眠内容”

点击房门时会播放约 520ms 的开门过渡，然后进入编辑场景。岛屿主视觉、云雾和其他物件在开门前后保持同一套素材，仅改变门的开合状态。

## 4. “开始沟通”页面

### 4.1 点选模式

页面标题为“开始沟通”，默认选中“点选”。当前有四组问题：

1. 今晚情绪：平静 / 有点烦 / 很累
2. 需要人声：需要 / 都可以 / 不要
3. 不想听到：水声 / 风声 / 人声
4. 预计使用：10 分钟 / 20 分钟 / 30 分钟

每组只能保留一个选中项。页面下方还有两个图文快捷方案和两句预制句。点击预制句会改变方案理由文案，但不会立即进入播放。

### 4.2 “说一句”模式

点击顶部“说一句”后，点选问卷隐藏，显示文本框。文本框是演示输入区，当前生成逻辑仍使用前端规则示例，不会调用真实大模型。

儿童模式且未设置 PIN 时，“说一句”入口会隐藏，只保留点选模式。

### 4.3 生成方案

点击“生成今晚方案”后：

1. 按钮短暂显示“生成中”及三个加载点。
2. 约 650ms 后出现方案卡。
3. 按钮文案变为“重新整理方案”。
4. 页面显示轻提示“已使用规则建议生成方案”。

方案卡当前展示“纯声景”、规则建议、30 分钟、最后 5 分钟渐弱，以及“小雨 / 壁炉 / 室内底噪”。

方案卡的两个动作：

- “去房间预览”：进入编辑器。
- “确认并开始”：在当前预览中直接进入睡眠模式，不经过额外的编辑确认页。

## 5. 声景编辑器实际交互

### 5.1 编辑器头部

进入编辑后，顶部显示：返回箭头、“编辑场景”、“撤销”和“保存”。普通品牌栏和主导航会隐藏。

点击返回会离开编辑器并回到首页；不会弹出保存确认。点击“保存”只保存草稿，不会退出编辑器，也不会自动开始播放。

### 5.2 声音盒

底部固定“声音盒”，当前只保留两个分类：

- 室内：雨打窗户、壁炉、翻书声、室内底噪、轻键盘、被子摩擦
- 户外：小雨、微风、水流声、柴火燃烧、夜晚森林、远雷

“雨打窗户”已经归入室内。点击“室内”或“户外”会同时完成三件事：

1. 切换声音卡片列表。
2. 切换卧室 / 雨夜小院背景。
3. 更新房间按钮和提示文字。

切换分类不会清空另一场景已添加的声音。

### 5.3 添加和移除声音

声音卡片支持点击和拖动两种方式：

- 点击卡片：显示一个跟手放置预览，继续拖动后在场景区域松手即可添加。
- 直接拖动卡片：拖动过程中显示推荐虚像、连接线和浮动图标。
- 在场景区域外松手：不添加，并提示“请松手在场景区域内放置素材”。
- 点击已放置的声音物件：移除该物件，并显示“已移除”。
- 点击“撤销”：撤销最后一次添加；没有可撤销内容时提示“没有可以撤销的操作”。

声音物件的大小、位置和阴影由当前声音的视觉规格控制。室内和户外只显示对应空间的物件，已添加物件不会因切换分类被删除。

### 5.4 保存与开始睡眠

点击“保存”后按钮短暂变为“已保存”并禁用，随后恢复；同时提示“场景已保存，可以开始睡眠”。这个动作不会把用户带离编辑器。

点击“开始睡眠”才会进入睡眠模式。如果当前没有声音，演示会自动放入壁炉、小雨和翻书声后再进入睡眠模式，这是演示兜底行为，不代表真实推荐逻辑。

## 6. 睡眠模式实际交互

睡眠模式使用当前室内或户外场景作为背景，并隐藏编辑器、内容中心和普通导航。页面只保留：

- 当前状态文字“声音正在陪着你”
- 剩余时间
- 暂停/继续
- 播放时长选择：15 / 30 / 45 / 60 分钟
- 睡眠模式音量
- 退出按钮

暂停后状态文字变为“已暂停”，按钮显示继续图标。退出会立即停止演示计时器，回到声景场景并提示“已结束本次播放”。当前预览不会写入真实播放记录。

## 7. 内容中心实际交互

内容中心顶部有返回键和收藏入口，分类为：声音、故事、呼吸、预设、收藏。

当前演示数据如下：

- 声音：壁炉、小雨、夜晚森林、远雷、翻书声、轻键盘、被子摩擦、室内底噪
- 故事：窗边听雨、静室入夜、暖茶时光、星星和小毯子、小小花园的晚安
- 呼吸：睡前两分钟呼吸
- 预设：暖火与细雨、林间留白
- 收藏：小雨、月光邮局、壁炉

点击声音或预设卡片的动作按钮只显示试听/载入提示，当前没有接入真实音频播放器。点击故事或呼吸卡片会进入统一的详情演示页。

详情页当前固定展示“月光邮局”，可以：

- 播放/停止试听按钮切换状态文字
- 收藏，收藏后图标变为完成状态
- 点击“加入今晚方案”，显示加入成功提示
- 点击“试听”，切换试听按钮状态

不同故事卡进入详情页后仍展示同一份月光邮局详情，这是当前演示实现的已知限制。

## 8. 睡眠档案与次日反馈

睡眠档案页面包含：

- “填写次日反馈”入口
- “个性化成长”卡片
- 120 积分入口
- 近 7 天 / 近 30 天切换
- 主观舒适度趋势
- 最近播放记录

点击“填写次日反馈”进入反馈页。三项选择全部完成后才能提交：

1. 是否容易入睡
2. 声音是否舒服
3. 还要不要人声

补充文字为可选，计数上限 100 字。未完成三项时提交会提示“请先完成三项选择”。

提交成功后页面会：

- 隐藏反馈表单，显示反馈结果卡
- 显示本次偏好变化
- 将积分从 120 更新为 125
- 将成长状态更新为“已从 7 次反馈中了解你”
- 把次日反馈卡改为“今日反馈已记录”
- 提示“已记入偏好，本次获得 5 积分”

这些变化当前只存在于本次页面会话，刷新后不会保留。

## 9. 积分页实际交互

积分页由睡眠档案右上角礼物图标进入。当前显示：

- 当前积分：120（提交反馈后变为 125）
- 获取积分：按计划开始 +10、提交反馈 +5
- 积分记录：今日反馈、昨天按计划开始，以及一条 -20 的演示记录

积分页只提供展示，没有兑换操作。底部说明积分用于鼓励完成计划和反馈，不评价睡眠好坏。

## 10. 设置与隐私实际交互

设置页包含账户与使用、体验设置、安全与说明三组。

### 10.1 使用模式与 PIN

- 点击“使用模式”在成人/儿童之间切换，并显示轻提示。
- 从儿童模式切回成人模式且已设置 PIN 时，会出现 PIN 验证对话框；当前演示点击确认即视为验证通过。
- 点击“儿童 PIN”会弹出设置 PIN 对话框；当前对话框没有真实四位数输入，仅用于标记“已设置”。

### 10.2 体验设置

通知、减少动态效果和隐私授权开关均为即时切换。开启提示“已开启”，关闭提示“已关闭并清理相关授权”。

### 10.3 说明和隐私

- “关于眠屿”：弹出版本和产品定位说明。
- “非医疗说明”：弹出不能诊断失眠、播放记录不代表实际入睡的说明。
- “隐私中心”：管理对话、播放摘要、噪声摘要和设备摘要四项授权。
- “撤回全部授权”：二次确认后关闭所有可选开关。
- “删除本机数据”：二次确认后模拟清理约 650ms，按钮变为“已清理”。

## 11. 当前页面反馈形式

当前界面使用三类反馈：

1. **按钮状态**：选中、禁用、加载中、已保存、已清理。
2. **轻提示 Toast**：用于添加、删除、切换、保存、试听和提交结果。
3. **确认对话框**：用于退出睡眠模式、删除数据、撤回授权、PIN 和说明操作。

没有真实后端时，Toast 和按钮状态只能说明演示状态，不代表数据已经写入服务器。

## 12. 当前已知演示限制

- 刷新页面会回到首次设置，状态没有持久化。
- 声音和故事的“试听”目前是界面状态切换，没有连接真实音频引擎。
- 详情页内容固定为月光邮局，未根据每张故事卡动态切换。
- PIN 对话框是确认模拟，不执行真实 PIN 校验。
- 删除数据、撤回授权和积分更新均为前端演示状态。
- 当前页面同时包含 Flutter 页面实现和静态预览实现，二者是同一产品交互的两种演示载体，不是两套业务流程。

## 13. 实际验收路径

1. 打开页面，完成首次设置并进入首页。
2. 点击首页房门，确认进入编辑器且声音盒显示室内/户外两类。
3. 将“雨打窗户”放入室内，切换户外后确认背景和卡片变化。
4. 添加一个声音，点击保存，确认仍留在编辑器。
5. 点击开始睡眠，验证暂停、时间、音量和退出。
6. 返回首页后进入开始沟通，切换点选/说一句，生成方案并查看方案卡。
7. 进入内容中心切换五个分类，打开故事详情并测试试听、收藏、加入方案。
8. 进入睡眠档案提交三项反馈，检查成长卡和积分变化。
9. 进入设置和隐私中心，验证开关、确认对话框和清理状态。
