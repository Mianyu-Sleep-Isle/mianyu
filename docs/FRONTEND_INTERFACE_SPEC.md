# 眠屿前端界面说明

版本：MVP v1.0  
适用范围：`mianyu_app` 的 Flutter 页面与静态浏览器预览  
最后整理：2026-09-22

## 1. 文档目的

本文说明眠屿前端的页面结构、导航关系、主要交互、视觉基线和模块边界，作为产品、视觉、前端和后续联调的共同依据。文档描述的是当前项目中的可运行实现，不把原型中的装饰性文字或静态素材当作功能。

当前有两种交付形态：

- Flutter 实现：`lib/`，使用页面组件、主题和 Fake Port 演示业务闭环。
- 浏览器预览：`system_preview.html`、`app_pages.js`、`app_pages.css`，用于快速展示移动端界面和交互。

## 2. 产品定位与体验目标

眠屿是一款低刺激、可解释、可修改的入睡辅助工具。用户先表达今晚的状态，系统生成结构化方案；用户可以进入声景空间调整声音，再进入低干扰播放，次日用主观反馈影响下一次推荐。

核心体验目标：

1. 三分钟内完成“表达状态 → 看懂推荐理由 → 调整声景 → 开始播放”。
2. 所有推荐都能修改，用户始终知道当前选择和下一步动作。
3. 播放记录、主观反馈和推测信息分开标注，不把播放时长当作真实睡眠时长。
4. 儿童模式是内容过滤，不复制一套 App；成人内容和自由对话由本机 PIN 保护。
5. 睡眠模式低亮度、少控件、无积分和复杂导航，避免打扰入睡。

## 3. 信息架构与导航

### 3.1 一级导航

普通页面底部导航固定为四项：

| 入口 | 页面 | 职责 |
|---|---|---|
| 眠屿 | 首页 | 查看今晚方案、房间和快速入口 |
| 编辑 | 声景编辑器 | 调整室内/户外声音及位置 |
| 档案 | 睡眠档案 | 次日反馈、个性化成长、记录和积分入口 |
| 设置 | 设置 | 使用模式、PIN、通知、隐私和说明 |

编辑器和睡眠模式是沉浸式流程，不显示底部导航。所有二级页面使用左上角返回按钮回到上一级；返回栈为空时回到首页。

### 3.2 页面流程

```text
首次设置
  → 首页
  → 今晚沟通
  → 方案结果
  → 声景编辑
  → 保存/冻结
  → 睡眠模式
  → 次日反馈
  → 睡眠档案与个性化成长
```

内容中心和设置可从首页或对应入口进入，不要求用户完成睡眠流程才能浏览。内容中心试听不会直接开始睡眠模式。

## 4. 页面说明

### P0 首次设置与年龄门

**目标**：完成成人/儿童模式、可选 PIN 和非医疗确认。

**界面结构**：品牌和产品介绍、成人/儿童选择、PIN 设置步骤、非医疗说明、可跳过的偏好选择。

**交互规则**：

- 未选择年龄不能进入首页。
- 儿童模式建议设置 PIN；成人模式 PIN 可选。
- 非医疗说明必须确认一次。
- 儿童模式隐藏自由沟通和成人故事；进入受限入口时显示 PIN 验证。

**状态反馈**：选择项使用高亮边框；保存完成后回到首页并显示轻提示。PIN 不在界面或日志中回显明文。

### P1 首页 / 眠屿

**目标**：提供今晚状态总览和最短行动路径。

**主要内容**：品牌栏、空间/岛屿主视觉、今晚方案卡、开始沟通、内容中心、进入编辑等快捷入口。

**交互规则**：

- 点击岛屿/房门进入声景编辑器，进入过程只改变门的开合状态，不替换其他场景内容。
- 有已确认方案时主操作进入房间或开始播放；没有方案时引导“开始沟通”。
- 首页不展示睡眠分期、深睡或疗效判断。
- 右上角模式按钮仅在确有模式切换需求时显示，不能承担主导航。

### P2 今晚沟通

**目标**：收集今晚需求，并生成可解释的 `SleepPlan`。

**输入方式**：默认点选；可切换到一句话输入。点选至少覆盖情绪、是否需要人声、可用时间和禁忌声音。

**方案卡必须展示**：方案类型、1–2 句理由、来源标签（规则建议/模型建议）、播放时长、渐弱时长和音轨摘要。

**操作**：修改选择、重新生成、去房间预览、确认并开始。生成中按钮禁用并显示加载反馈；建议服务不可用时改用规则建议，不暴露内部错误。

### P3 内容中心

**目标**：浏览、试听和收藏可用内容。

**当前分类**：声音、故事、呼吸、预设、收藏。声音卡片按内容类型展示名称、时长、年龄包和可用状态；故事/呼吸卡片使用同一套卡片结构和项目素材。

**声音与编辑器的关系**：编辑器声音盒只保留“室内 / 户外”两个分类；“雨打窗户”归入室内。点击分类后直接展示对应场景的声音卡片，卡片可试听或拖入场景。

**可用性规则**：

- 未审核、被年龄模式限制或暂不可用的内容必须禁用，并用用户能理解的原因说明。
- 故事详情不添加“已审核”等内部流程字段。
- 呼吸内容使用面向用户的训练名称和时长，不展示内部资源标记。

### P4 故事/呼吸详情

**目标**：让用户在加入方案前了解内容。

展示封面、名称、时长、主题、年龄适用范围、试听按钮和“加入今晚方案”。未满足年龄或资源条件时，主按钮禁用并说明原因。页面底部固定非医疗声明；模板故事标注为模板内容，不伪装真人陪伴。

### P5 声景编辑器

**目标**：让用户理解并调整声音在二维空间中的位置、远近和音量。

**场景**：

- 室内：卧室/房间背景，展示室内声音。
- 户外：雨夜小院背景，展示户外声音。
- 切换场景只切换画面和当前分类，不清空已添加的声音。

**声音盒**：底部抽屉式面板，包含室内/户外切换、四列声音卡片、当前场景提示、音量控制和开始播放入口。声音图标使用透明 PNG；SVG 保留在 `assets/images/icons/` 作为源图标。

**放置方式**：

- 点击卡片进入跟手放置预览。
- 拖动卡片，在场景区域松手后生成声音物体。
- 已放置物体可再次拖动、试听、调整音量或删除。
- 方向按钮提供拖动之外的无障碍微调方式。
- 禁用素材不可放置，显示简短提示。

**保存逻辑**：保存只保存当前草稿；冻结后才允许进入睡眠模式。保存不会退出编辑器，也不会自动开始播放。用户可继续添加、试听或返回首页；需要播放时使用明确的“开始播放/进入睡眠模式”动作。

### P6 睡眠模式

**目标**：执行已确认方案，保持低干扰。

只保留睡眠标题、剩余播放时间、暂停/继续、音量和退出。退出必须二次确认，确认后停止播放并回到首页。倒计时结束显示渐弱状态，不显示“已入睡”、睡眠质量或医疗判断。

### P7 次日反馈

**目标**：收集明确的主观反馈，帮助下一次方案个性化。

固定三项：是否容易入睡、声音是否舒服、还要不要人声；可选补充一句，最多 100 字。提交后展示“已记入成长档案”、本次偏好变化和反馈积分。重复提交同一会话不可重复记分。

### P8 睡眠档案

**目标**：把反馈和播放事实呈现为可理解的成长记录。

页面包含：待完成的次日反馈卡、个性化成长卡、主观舒适度趋势、最近记录和来源标签。

- “主观反馈”只来自用户选择。
- “播放记录”只说明应用实际播放过什么。
- “推测（非测量）”只用于说明期间没有操作应用，不能解释为睡眠结果。
- 页面底部展示非医疗声明。

### P9 积分

只记录“按计划开始”和“提交反馈”两类正向行为。积分不与播放时长、睡眠深度或连续天数绑定，不使用惩罚性断签文案。

### P10 隐私中心

提供四项独立授权：对话相关、播放摘要、噪声摘要、设备摘要。敏感授权默认关闭；撤回全部授权和删除本机数据均需二次确认，并显示清理成功/失败状态。删除本机数据不影响基础界面浏览。

### P11 设置

包含使用模式、儿童 PIN、通知、减少动态效果、夜间亮度、隐私中心、关于眠屿和非医疗说明。设置页和睡眠档案页不放首页岛屿素材或与首页重复的场景装饰，保持信息页的阅读清晰度。

## 5. 视觉与交互基线

### 5.1 色彩与层级

| Token | 用途 | 当前值 |
|---|---|---|
| `night` | 页面主背景 | `#07132E` |
| `nightDeep` | 深层背景/睡眠模式 | `#030918` |
| `surface` | 卡片和导航 | `#0E2142` |
| `surfaceRaised` | 输入、选中前景 | `#162D52` |
| `primary` | 选中态、主链接 | `#5C7CFA` |
| `accent` | 开始播放、积分强调 | `#FFA24C` |
| `text` | 主文字 | `#F5F7FF` |
| `textMuted` | 辅助文字 | `#C3CEE7` |
| `border` | 卡片边框 | `#38527F` |

视觉关键词是“深靛蓝、低光、半透明层、暖橙行动色、柔和星点”。装饰素材应作为背景层或透明 cutout 融入，不以硬卡片形式覆盖内容；设置、档案等信息页优先保证文字可读性。

### 5.2 版式与触控

- 移动端竖屏优先，页面宽度跟随视口，不依赖固定 430px 内容。
- 可点击控件最小触控区域约 44×44px，控件之间保留至少 8px 间距。
- 卡片圆角、边框、阴影和间距使用主题 token，避免页面各自定义一套数值。
- 文本正文不小于 14px；辅助信息不低于 11–12px，并保证与背景有足够对比。
- 重要图标按钮必须有可读的 `aria-label` 或等效语义标签。

### 5.3 动效与反馈

- 动效只解释状态变化：门开合、拖放跟手、加载点、选择高亮和轻提示。
- 支持 `prefers-reduced-motion`；减少动态效果开关应降低而不是删除必要反馈。
- 保存、生成、删除、退出等动作都要有即时状态反馈，禁止无响应点击。
- 睡眠模式不使用连续闪烁、强对比倒计时或庆祝动画。

## 6. 组件与代码边界

### Flutter

| 目录 | 职责 |
|---|---|
| `lib/presentation/screens/` | 页面组件：首页、沟通、内容中心、编辑、睡眠、档案、反馈、积分、隐私、设置 |
| `lib/presentation/widgets/components.dart` | 共享按钮、标签、方案卡、音轨标签、空态和非医疗页脚 |
| `lib/presentation/theme/app_theme.dart` | 颜色、间距、圆角、文字和 Material 主题 |
| `lib/app_controller.dart` | 页面状态编排、流程状态和 Port 调用 |
| `lib/domain/contracts.dart` | DTO、枚举和跨模块 Port；页面不读取模块内部模型 |
| `lib/data/fake_services.dart` | 演示用 Fake 数据和规则回退 |

### 浏览器预览

| 文件 | 职责 |
|---|---|
| `system_preview.html` | 首页、编辑器、睡眠模式和静态资源引用 |
| `app_pages.js` | P0–P11 页面模板、路由、表单和交互状态 |
| `app_pages.css` | 信息页、卡片、导航、反馈和响应式样式 |
| `preview_server.js` | 本地静态服务器，默认监听 `127.0.0.1:4173` |
| `index.html` | 进入 `system_preview.html?v=59` 的预览入口 |

前端只通过 `AppPorts` 使用内容、方案、场景、睡眠会话、反馈、积分和隐私能力。真实模块接入时替换 Adapter，不改页面 DTO 和交互边界。

## 7. 状态、错误与文案

| 场景 | 用户可见文案 |
|---|---|
| 表单不完整 | 这项还不完整，改一下再试 |
| 内容找不到 | 找不到这个内容 |
| 儿童内容受限 | 当前是儿童内容包，需要 PIN 才能打开 |
| 内容暂不可用 | 这个声音暂时不能用 |
| 故事不可播放 | 这个故事还不能播放 |
| 保存失败 | 没能保存，请再试一次 |
| 播放失败 | 播放出了问题，已停止 |
| 建议服务失败 | 建议服务不可用，已改用规则建议 |
| 编辑草稿已保存 | 已保存，可以继续调整 |
| 反馈提交完成 | 已记入成长档案 |

禁止使用“已入睡、睡眠质量、治疗失眠、深睡、诊断”等暗示医疗判断或精确测量的表述。

## 8. 素材规范

素材目录：

- `assets/images/scenes/`：卧室、雨夜小院和首页场景背景。
- `assets/images/sounds/`：声音盒使用的透明 PNG。
- `assets/images/icons/`：声音 SVG 源图标。
- `assets/images/content/`：故事和呼吸卡片图片。
- `prototype_images/`：原型、切图和生成素材归档，不直接作为页面文字或交互的替代品。

新增素材要求：透明 cutout 优先、边缘柔和、色温统一为深蓝夜景和暖橙高光；必须在小屏和大屏检查比例，避免底部溢出、重复叠图或与文字冲突。信息页默认不放首页岛屿、月亮、星点等大面积场景素材。

## 9. 本地运行与验收

### 浏览器预览

在 `mianyu_app` 目录运行：

```powershell
node preview_server.js
```

打开 `http://127.0.0.1:4173/system_preview.html`。也可以直接打开 `index.html`，它会跳转到当前预览版本。

### Flutter

```powershell
flutter pub get
flutter run
```

### 最小验收路径

1. 完成首次设置并进入首页。
2. 从首页进入今晚沟通，选择预制句并生成方案。
3. 检查方案理由、来源、时长和音轨摘要。
4. 进入编辑器，切换室内/户外，添加声音并调整位置、音量。
5. 保存草稿、冻结场景，再进入睡眠模式。
6. 暂停/继续并确认退出回到首页。
7. 打开次日反馈，提交三项选择，检查档案中的偏好更新和积分。
8. 切换儿童模式，确认成人故事和自由沟通被 PIN 保护。
9. 检查设置和档案没有多余首页素材，检查所有页面在不同高度下无底部截断。
