## 默认与推荐状态

A12 的 `exclusionTestOnly=true`，`isDefault=false`，`isDefaultCandidate=false`，`allowRecommendation=false`，`enabled=false`。其用途固定为“仅用于不要打雷的排除验证”。即使未来补齐版权，也不能进入默认、推荐或用户显式选入的生产方案。

其余五类各保留一个 `isDefaultCandidate=true` 的预选项，按本类实际时长最长选定。这是可复现的初选，不是试听质量结论。全部素材的 `isDefault=false`、`allowRecommendation=false`、`enabled=false`：源包没有版权凭证，也未完成逐条人工听审，因此 `copyrightStatus=pending_review`。后端文档明确要求这些状态不能播放。完成授权与听审后可在本地维护的副本中启用非 A12 素材。

A09 原文件名显示其中有雨与虫鸣混合、蛙声与虫鸣混合素材，不能声称全部是纯虫鸣或树叶声。分类保留原包类别，并补充文件名可确定的标签；没有捏造树叶音频。

## 检查方法与边界

已逐个解析所有 MPEG Layer III 帧，累计帧样本数计算时长，记录采样率、声道与码率，检查源 ZIP CRC，计算 SHA-256 并核对交付音频与原包字节一致。时长未扣除编码器延迟和尾部填充，播放器显示可能相差少量毫秒。逐帧结构检查不等于完整解码或人工试听；未宣称无突发响声、无语音、无雷声、无缝循环或适合儿童。上线前仍应逐条听审，特别是混合环境声。

已读取设计说明和后端开发文档中的统一约束、HTTP API v1、成员1内容中心及成员2方案规则。后端压缩包仅含 Markdown 开发文档，没有可运行服务、数据库建表文件或实际 repository 实现。因此本包提供契约对齐的种子输入与接入说明，没有声称已连接或部署实际接口。

本次范围是用户指定的自然声最终交付包。设计文档所述完整内容中心还包括故事、呼吸训练、预设、收藏和分享；这些内容与完整后端功能不能由本包的 19 个音频替代，也未制造缺失素材。后端文档提出的完整模块种子数量与其他内容类别，需在团队完整工程中继续验收。
