# 眠屿 Flutter 前端

本目录是按 `前端设计与页面规范.md`、冻结数据契约和成员四素材生成的 MVP 前端。

## 已覆盖

- P0–P11 全部页面与四项主导航
- 点选/四条预制句 → 可解释方案 → 房间预摆 → 保存冻结 → 睡眠模式
- 儿童模式与 PIN 门控、内容审核/版权不可用状态
- 室内/室外切换、声音物体拖放，以及无障碍方向按钮替代
- 次日三项反馈、来源标签、积分、隐私授权和本机数据删除
- 10 个 DTO、12 个 Port、Fake 实现与集中式演示状态
- 真实卧室、小院、方形圆角 / 圆形两套 App 图标和 12 个声音视觉素材
- 编辑器按成员四参考界面采用移动端底部声音盒：室内 / 户外 / 故事分类、四列横向滑动图标卡、全屏跟手拖放与固定推荐虚像；同步收录 12 个 SVG 源图标到 `assets/images/icons/`
- `system_preview.html` 联合 `app_pages.css`、`app_pages.js` 提供不含 P0–P11 开发标记的完整移动端使用流程：首次设置、首页、今晚沟通、内容与详情、声景编辑、睡眠模式、次日反馈、档案、积分、隐私与设置
- 四项一级导航固定为「眠屿 / 编辑 / 档案 / 设置」；除声景编辑器外使用独立的深靛蓝低光背景，不复用卧室和雨夜小院图
- 档案页将次日反馈、明确偏好更新、主观舒适度趋势与积分串成可见的个性化成长闭环

## 运行

需要 Flutter 3.x：

```bash
flutter pub get
flutter run
```

当前代码仅依赖 Flutter SDK，不依赖第三方 UI、状态管理或 SVG 包。

无需 Flutter 时，也可以在本目录启动静态服务器后打开：

```text
http://127.0.0.1:4173/system_preview.html
```

## 边界

演示使用 Fake Port，不实现真实音频引擎、数据库、LLM 或模块内部 Repository。后续把 `FakeAppPorts` 替换为成员交付的 Adapter 即可，页面无需读取模块内部类。
