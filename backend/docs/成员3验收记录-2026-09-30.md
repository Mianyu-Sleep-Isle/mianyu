## 坐标、所有权、回滚、状态、幂等和复制

坐标：

- 提交 `positionX=0.72`、`positionY=0.38`，对应页面的 72 和 38。GET 读回这两个值。
- 配置 `spaceType` 仍是 `indoor`，元素自己的 `spaceType` 是 `outdoor`。
- `positionX=1.2` 返回 400 `INVALID_REQUEST`。随后 GET 仍是 0.72。

所有权：

- 另一个 `X-Mianyu-User-Id` 读取同一场景，返回 403 `SCENE_FORBIDDEN`。

事务回滚：

- 自动测试“插入失败后旧快照保持不变”通过。元素绑定了本次快照里不存在的声源，插入失败后旧快照与保存结果深度相等，`ghost` 元素行数为 0，当次 `PRAGMA foreign_key_check` 为空。
- HTTP 上把素材标成不可播放后再 PUT，返回 409 `SCENE_ASSET_UNAVAILABLE`。这条在进入替换事务之前被拒绝。失败后 GET 的 `updatedAt` 和声源 `assetId` 与失败前一致。

状态冲突：

- 声源全部关闭时 hand-off 返回 409 `SCENE_NO_ENABLED_SOURCE`，状态保持 `draft`。
- 有启用声源时 hand-off 返回 200 `handed_off`。
- 把素材改成不可播放后再次 hand-off，仍返回 200，`handedOffAt` 和 `updatedAt` 与第一次相同。
- 对已交接版本 PUT，返回 409 `SCENE_ALREADY_HANDED_OFF`。

复制：

- copy 返回 201，`configVersion=2`。
- `previousVersionId` 等于被复制的 `9640405a-6ffa-4faf-b1c8-62f4736c0219`。
- `sceneFamilyId` 与旧版相同。
- 新声源 id 为 `ac2bec6e-4cc9-4714-b7f0-3df0661cfd13`，不是请求里的原声源 id。
- 旧版 GET 仍是 `handed_off`，`handedOffAt` 未变。

幂等：
